Déboguer Anaconda

Parfois, les paquets ne s’installent pas comme voulu (ce qui entraîne des erreurs d’importation, Anaconda Navigator ne se comporte pas comme prévu ou ne démarre pas du tout. Cette page résume les solutions à ces problèmes.

Conda création d’environnement jamais fini¶

Phenomenon : la création d’un environnement conda avec et fichier environnement (conda env create -f environment.yml) entraîne une charge quasi éternelle sans que l’environnement soit installé même après plusieurs heures.

Fix: Before creating the environment, set the installation priority to strict (answer adapted from https://stackoverflow.com/questions/63734508/stuck-at-solving-environment-on-anaconda):

conda config --set channel_priority strict

L’installation du paquet Coda échoue¶

Phenomenon: L’installation d’une bibliothèque ou d’un paquet Python via Anaconda Prompt échoue.

Fix: Plusieurs raisons peuvent expliquer que l’installation de nouveaux paquets échoue dans Anaconda Prompt ou Linux / macOS Terminal:

  • Assurez-vous de fermer toutes les applications dépendantes de Python (par exemple, Jupyter ou PyCharm) avant d’installer.

  • La résolution des conflits s’active :

    • Attendez que les conflits soient analysés (et résolus)

    • Entrez conda update conda

    • Entrez conda update anaconda

    • Redémarrage Terminal ou Anaconda Prompt

    • Essayez de réinstaller le paquet demandé.

Anaconda Navigator ne démarre pas¶

Les problèmes les plus courants pour Anaconda ne démarrent pas sont listés dans le documents du développeur et comprennent:

  • Supprimer un fichier potentiellement corrompu .condarc. Pour ce faire, ouvrez Anaconda Prompt (sur Windows) ou Terminal (sur Linux ou macOS) et entrez :

    • conda info pour savoir où se trouve le fichier .condarc (sur Windows typiquement C:\Users\Username),

    • Ouvrir le répertoire indiqué (par exemple, dans l’explorateur Windows),

    • Supprimer le fichier .condarc.

  • Essayez de lancer Anaconda Navigator de Anaconda Prompt (ou Linux / macOS Terminal) en entrant anaconda-navigator.

  • Réparez les problèmes de perfmission en supprimant le répertoire .continuum:

    • Windows: Ouvrez Anaconda Prompt et lancez rd /s .continuum

    • Linux / macOS : Ouvrir Terminal et exécuter rm -rf ~/.continuum

  • Mise à jour Anaconda Navigator de Anaconda Prompt (ou Linux / macOS Terminal) en entrant conda update anaconda-navigator

  • Réinstaller Anaconda Navigator de Anaconda Prompt (ou Linux / macOS Terminal) en exécutant :

    • conda remove anaconda-navigator

    • conda install anaconda-navigator

  • Réinitialiser la configuration Anaconda Navigator de Anaconda Prompt (ou Linux / macOS Terminal) en exécutant anaconda-navigator --reset (caution: ceci peut être destructeur).

D’autres, bug-fixes, qui ne sont pas listés sur le site du développeur mentionné ci-dessus sont:

  • Réinitialisez conda de Anaconda Prompt (ou Linux / macOS Terminal) en exécutant conda init. Puis, fermez et rouvrez Anaconda Prompt (ou Terminal).

  • Mettre à jour conda et Anaconda Navigator de Anaconda Prompt (ou Linux / macOS Terminal) comme racine :

    • activate root

    • conda update -n root conda

    • conda update --all

    • conda update anaconda-navigator

  • Réinstaller PyQt5 de Anaconda Prompt (ou Linux / macOS Terminal):

    • pip uninstall PyQt5

    • pip install PyQt5

    • pip install pyqtwebengine

Grande taille de stockage de Anaconda¶

L’environnement Anaconda base est livré avec de nombreux paquets préinstallés et peut être très intensif de stockage dans l’ordre de nombreux gigaoctets. Chaque nouvel environnement produit peut prendre la même taille et plusieurs environnements conda peuvent bloquer votre disque dur. Encore une fois, il y a quelques solutions:

  • Créer des environnements légers avec Miniconda.

  • Nettoyer les fichiers d’installation de paquets inutiles avec Anaconda Prompt ou Linux / macOS Terminal:

    • Nettoyage agressif : conda clean --all (en savoir plus dans les documents du développeur](https://docs.conda.io/projects/conda/en/latest/commands/clean.html)).

    • Nettoyage conservateur : conda clean -tipsy

Impossible de trouver ... chemin¶

Dans Anaconda Prompt ou Linux / macOS Terminal exécuter conda init et redémarrer l’application.
