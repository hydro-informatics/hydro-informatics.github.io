Charriage sur l’Arbogne : grain, rugosité et diagramme de Shields

Pour travailler de manière interactive , ou téléchargez le notebook et installez Python et JupyterLab en local pour exécuter bedload-exercise.ipynb sur votre ordinateur.

Important

L’exercice comprend trois fichiers qui doivent garder cette structure de dossiers. Ne téléchargez pas le fichier zip du dépôt jupyter-python-course (il contient tous les notebooks et toutes les données du cours) : téléchargez les trois fichiers un par un (sur GitHub : Download raw file).

fichiercontenu

Tâche

Votre expertise est demandée pour analyser le risque d’alluvionnement dans le tronçon revitalisé de l’Arbogne. Un collègue vous a fourni l’hydraulique (1D) de 16 profils sur 890 m. Où le gravier s’arrête-t-il, et que se passe-t-il quand la végétation freine l’écoulement ?

Les endroits à compléter sont marqués par le commentaire # >>> À COMPLÉTER : remplacez chaque texte ">>> COMPLETER" (guillemets compris) par votre valeur ou votre équation. Dans le code, les nombres décimaux s’écrivent avec un point (0.047 et non 0,047).

Diagramme de Shields¶

Le diagramme compare les deux cas de rugosité, sans végétation (écoulement dans le lit) et avec végétation (crue débordante dans la plaine inondable), pour les deux classes de grain, gravier et sable. Chaque point est un profil. L’axe vertical est la contrainte efficace sur les grains k′ τ∗k'\,\tau_*k′τ∗​, celle que MPM compare à τ∗,cr\tau_{*,cr}τ∗,cr​. Sous la courbe de Shields critique, il n’y a pas de charriage.

  • couleur : cas de rugosité (bleu sans végétation, rouge avec végétation) ;

  • symbole : classe de grain (rond : gravier ; triangle : sable) ;

  • taille : Φ\PhiΦ, une décade par classe (le plus grand Φ\PhiΦ donne le plus grand marqueur).

ch.diagramme_shields(resultats)
Note

Avec dmd_mdm​ = 0,23 mm, le sable est hors du domaine de validité de MPM (environ 0,4 à 30 mm). Son résultat n’est qu’un ordre de grandeur.
