## NotepadPlusPlus (éditeur de texte)
[Notepad++](https://notepad-plus-plus.org/) est un éditeur de texte complet pour le codage de base (*R*, *Python*, *Java*, *C*, *Perl*, ...), le balisage/html et beaucoup d'autres (pas un typo). Les alternatives Linux pour Notepad++ sont, par exemple, [Sublime text](https://www.sublimetext.com/) (propriétaire), [Kate](https://kate-editor.org/) (plateforme croisée) ou [Gedit](https://help.gnome.org/users/gedit/stable/) (simpliste).

## Demandes présentées par des bureaux

Les applications bureautiques simplifient grandement la vie quotidienne du bureau. Cependant, l'application la plus populaire de Microsoft a un prix élevé. Voici quelques alternatives gratuites.

### Bureau libre

[LibreOffice][libreoffice] est entièrement libre d'utilisation (voir leurs [licence terms](https://www.libreoffice.org/about-us/licenses)) et fonctionne sur les plateformes les plus populaires. Les versions récentes offrent des interfaces utilisateur grandement améliorées, avec la possibilité d'organiser des menus en onglets, comme d'autres suites de bureau.

### Bureau unique

Only Office resembles MS Office a lot, it is very intuitive and enables cloud-based collaboration. It is free to use for non-commercial purposes and comes at an OK price for commercial purposes. On any Ubuntu Linux-based platform (e.g., Ubuntu, Mint, or Lubuntu), it is available through the software manager (or snap, flathub, or whatever you use...). Mint users find more information at [https://community.linuxmint.com](https://community.linuxmint.com/software/view/org.onlyoffice.desktopeditors).

For more installation options (e.g., for other Linux platforms, macOS, or Windows) visit the DesktopEditors section on [https://www.onlyoffice.com](https://www.onlyoffice.com/desktop.aspx).

```{admonition} Look for DesktopEditors to use Only Office for free
:class: tip

Make sure to follow the non-commercial desktop-use installation instructions on [https://www.onlyoffice.com](https://www.onlyoffice.com/desktop.aspx). Other versions are not for free.
```

De nombreux plugins pour enrichir Only Office sont disponibles sur GitHub. Pour les installer, téléchargez/clonez les plugins (sous forme de fichier zip) de GitHub. Assurez-vous de décompresser le dépôt et d'emballer les fichiers et dossiers suivants dans un fichier `.zip`: `config.json`, `scripts/`, `pluginCode.js`, `licenses/`, `resources/`, `translations/`, `LICENSE`. Certains de ces fichiers ou répertoires pourraient ne pas être disponibles dans tous les repos de plugin, que vous pouvez vouloir omettre dans ces cas. En outre, le fichier `pluginCode.js` pourrait être caché dans le dossier `scripts/` et si tel est le cas, copier le fichier `.js` (par exemple, `scripts/pluginName.js`) dans le dossier principal et le renommer à `pluginCode.js`. Puis renommer l'archive zip à `name.plugin` (remplacez le `name` du plugin), ouvrir Only Office, aller à l'onglet **Plugins**, **Paramètres**, et utiliser le bouton **Add** pour localiser et ajouter le plugin.


Voici une liste de plugins utiles:

* [Le compteur de mots](https://www.onlyoffice.com/en/app-directory/word-counter) aide à compter le nombre de caractères, de mots, d'espaces, etc. Obtenez-le à [GitHub.com/ONLYOFFICE/plugin-wordscounter](https://github.com/ONLYOFFICE/plugin-wordscounter). Le plugin fait maintenant partie de l'installation standard
* [LanguageTool](https://www.onlyoffice.com/app-directory/languagetool) vérifie votre écriture dans de nombreuses langues, y compris les tests de sort et de grammaire. Le plugin est basé sur le [LanguageTool](https://languagetool.org/) correcteur orthographique. Obtenez-le à [GitHub.com/ONLYOFFICE/plugin-languagetool](https://github.com/ONLYOFFICE/plugin-languagetool).
* [Draw.io](https://www.onlyoffice.com/blog/2022/03/onlyoffice-integrates-draw-io/) aide à créer des diagrammes et des graphiques professionnels pour n'importe quel document de bureau unique. Obtenez-le à [GitHub.com/ONLYOFFICE/plugin-drawio](https://github.com/ONLYOFFICE/plugin-drawio).
* [SDKJS](https://github.com/ONLYOFFICE/sdkjs-plugins) permet l'intégration de vidéos (YouTube), l'édition de photos, la génération de graphiques avec Draw.io, l'organisation des leçons, et tweaks dans un couple de traducteurs ([read more](https://www.onlyoffice.com/blog/2022/08/best-onlyoffice-plugins-for-online-educators/)). Remarque : ce plugin nécessite plus d'ajustement et vous pouvez préférer installer des plugins sdkjs singuliers en les cherchant avec votre moteur de recherche préféré.

## Annotations PDF (édition) avec Xournal++

Xournal++ est un logiciel gratuit de prise de notes pour annoter les PDF, les croquis et les notes d'écriture. C'est une nouvelle version du projet original Xournal et a plus de fonctionnalités et un look moderne. Il peut calquer des images, utiliser différents stylos et surligneurs, et importer et exporter des fichiers dans différents formats. Sa compatibilité multiplateforme en fait un outil puissant pour les étudiants, les chercheurs et les professionnels à la recherche d'une solution de prise de notes numérique flexible. Par exemple, Xournal++ facilite la prise de notes sur les PDF lors de réunions, conférences ou conférences, et facilite le dessin et la réalisation de croquis.

Windows and MacOS users can find installation instructions at [https://xournalpp.github.io](https://xournalpp.github.io/). Debian/Ubuntu/Mint/Lubuntu (and similar) Linux users can install Xournal++ using

```
sudo apt install xournalpp
```

## LaTeX & TeXstudio

TeXStudio est un éditeur graphique conçu pour vous aider à écrire et organiser le code LaTeX avec des fonctionnalités comme la mise en surbrillance syntaxique, la vérification orthographique, l'auto-complètement et un visionneur intégré. De plus, une distribution TeX telle que [TeX Live](https://tug.org/texlive/) (Préférence Linux) ou [MiKTeX](https://miktex.org/) (Préférence Windows) est requise, car ce sont les compilateurs LaTeX qui fournissent les paquets et les polices nécessaires pour transformer un fichier source `.tex` en document PDF. Tant un éditeur (c'est-à-dire TeXstudio) qu'une distribution TeX sont nécessaires, car l'éditeur seul ne peut pas compiler le code, et la distribution seule ne fournit pas un environnement intégré pour l'écriture et la gestion des documents LaTeX. Par conséquent, avant d'installer l'éditeur graphique LaTeX, assurez-vous d'installer une distribution TeX -- l'éditeur LaTeX tentera de trouver la distribution TeX installée lors de sa propre installation (étape suivante).


`````{admonition} LaTeX package installation
:class: important

LaTeX packages are collections of additional commands, macros, and formatting instructions that extend the capabilities of the LaTeX system. Packages are typically introduced into a TeX document by including commands such as `\usepackage{...}` in the preamble of a `.tex` file. This allows authors to leverage specialized functionality, such as enhanced math notations, improved bibliography management, or particular typographic styles, without having to redefine or recode basic LaTeX commands. A TeX distribution comes bundled with a large set of commonly used packages and is often configured to retrieve more packages as needed. If a source file calls for a package that is not installed locally, the distribution can automatically download and install it from a central repository, ensuring that you have the resources required to compile the `.tex` file into a PDF document without manually searching and installing additional files.

````{tab-set}
```{tab-item} Linux (Debian)
Les utilisateurs de Debian Linux peuvent simplifier l'installation des paquets en installant en vrac tous les paquets TeX Live disponibles avec `sudo apt install texlive-full`, mais cela prendra 3-4 Go d'espace disque.
```

```{tab-item} Windows

Il est conseillé aux utilisateurs de Windows d'installer MiKTeX en utilisant un compte utilisateur standard plutôt que des privilèges d'administrateur. Cela permet à MiKTeX de télécharger et d'installer de nouveaux paquets *à la volée* sans demander à plusieurs reprises des autorisations à l'échelle du système. Si MiKTeX était installé par un administrateur, toute installation supplémentaire de paquets nécessiterait des droits élevés et inciterait l'utilisateur à s'authentifier en tant qu'administrateur à chaque fois, un processus qui est à la fois gênant et potentiellement moins sécurisé. Au lieu de cela, effectuer une installation de niveau utilisateur garantit que MiKTeX peut écrire des paquets directement dans les répertoires utilisateurs actuels. Lors de l'installation, sélectionnez l'option d'installation réservée à l'utilisateur et répondez « Non » lorsque vous êtes invité à utiliser les droits d'administrateur. Après la configuration, ouvrez le panneau de paramètres MiKTeX et confirmez que l'installation du paquet *on-the-fly* est activée.
````` 

## GNU Octave (Matlab&reg; alternative)
*Matlab*&reg; est toujours l'un des principaux outils en sciences et en génie. Toutefois, les droits de licence et leur nature exclusive limitent l'utilisation de *Matlab*&reg; aux entités et utilisateurs privilégiés. La bonne nouvelle est qu'il y a un remède en forme de [GNU Octave](https://www.gnu.org/software/octave/). *GNU Octave* et *Matlab*&reg; utiliser une syntaxe très similaire et les fichiers `.m` peuvent être exécutés avec les deux programmes.
Si des messages d'erreur se produisent en exécutant un fichier `.m` avec GNU Octave, assurez-vous de charger les paquets pertinents en haut du script (c'est l'une des principales différences entre *GNU Octave* et *Matlab*&reg;). Par exemple:

```
pkg load io
# ... some script with console output
pkg unload io
```

All stable *GNU Octave* packages can be found at [https://packages.octave.org](https://packages.octave.org). To install one of these packages, open *GNU Octave* and type in the command window:

```
pkg install "<package-link>"  # installs the package
pkg load <package-name>  # loads the package in the active session
```

Ensuite, le nouveau paquet peut être chargé à tout moment en tapant `pkg load <package-name>`. Par exemple, l'extrait de code suivant installe et charge le paquet `statistics` :

 ```
pkg install "https://github.com/gnu-octave/statistics/archive/refs/tags/release-1.6.6.tar.gz"
pkg load statistics
```
