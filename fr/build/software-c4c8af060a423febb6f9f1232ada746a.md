# Ouvrir Acces & Source

Le présent chapitre s'appuie sur des ressources en libre accès ou en libre accès. La première section présente les machines virtuelles (VM) et *Debian Linux* (et spin-offs).

```{admonition} The difference between Open Access and Open Source
Le logiciel libre est disponible gratuitement sous licence ouverte commune. En plus d'être disponible gratuitement, le logiciel open source s'appuie sur le code source accessible au public. Ainsi, le logiciel open source peut être modifié par des utilisateurs avec un code librement disponible sur Internet. Pour permettre le partage d'accès libre ou de logiciels libres, le développeur doit fournir une licence avec le code ou le logiciel. Pour en savoir plus sur les licences sur la plate-forme de [créative commons organization](https://creativecommons.org/).
```

Linux-basé {term}`Operating System`s (OS) facilite grandement les tâches scientifiques et techniques liées aux données en raison de la très haute stabilité et performance. Néanmoins, l'infrastructure existante de nombreuses institutions ne permet pas d'utiliser Linux et c'est là que les machines virtuelles peuvent aider : Ils permettent d'exécuter un autre OS (invité) sur l'OS hôte à travers un cadre de virtualisation.

Le logiciel présenté dans cette section n'est pas seulement fait pour Linux et peut être installé principalement sur beaucoup d'autres OS, aussi. Profitez de la lecture et de l'exécution des tutoriels sur les logiciels géospatials, git, logiciel de modélisation numérique et d'autres programmes utiles.
