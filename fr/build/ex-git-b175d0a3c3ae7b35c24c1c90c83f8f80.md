# Git et Markdown

```{admonition} Goals
Utilisez *git* et familiarisez-vous avec l'écriture des documents de balisage.
```

```{admonition} Requirements
:class: attention
Comprendre [git](../get-started/git) et [markdown](../documentation/how-to-document).
```

Préparez-vous en clonant le dépôt d'exercices :

```
git clone https://github.com/Ecohydraulics/Exercise-git.git
```

***Activité:*** Décrivez votre barrage, poisson ou rivière favori dans un fichier de balisage nommé `README.md`.

```{admonition} Features to implement in the `README.md` file
:class: attention


* Lien vers l'image en ligne
* Écrire au moins 150 mots sur l'objet
* Tableau résumant les principaux paramètres
* Énumérer au moins deux structures / rivières / poissons similaires
* Mettre en place des liens cliquables vers les sources (site Web, téléchargements pdf) utilisées

---

[illustration](https://raw.githubusercontent.com/hydro-informatics/hypy-assignment-1/master/illustration.png)
```
