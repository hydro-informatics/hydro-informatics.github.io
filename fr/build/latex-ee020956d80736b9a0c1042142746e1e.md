# LaTeX & Citation Management (Zotero)

Les éditeurs LaTeX en ligne, tels que Overleaf, offrent une collaboration pratique en temps réel et une compilation basée sur le cloud, mais des fonctionnalités avancées comme la gestion de documents plus importants ou une vaste collaboration d'équipe nécessitent souvent un abonnement payant. En revanche, travailler localement avec un éditeur dédié comme TeXstudio (voir {ref}`LaTeX installation <install-tex>`) vous permet d'éditer et de compiler des documents sans dépendre d'une connexion Internet tout en écrivant/compilant et sans encourir de frais d'abonnement. Cette page est destinée à fournir des conseils sur l'utilisation efficace de LaTeX dans un environnement local.


## Texte clair et comptage des mots

Pour estimer le nombre de mots dans un manuscrit LaTeX en utilisant TeXstudio, commencez par créer une version en texte simple de votre document. Dans le menu **Tools**, sélectionnez **Convertissez vers Abridged Plaintext**, qui ouvre un nouvel onglet sans titre contenant votre texte sans commandes LaTeX. Ce fichier dépouillé convient également pour le partage avec les collaborateurs qui préfèrent les processeurs de texte (richtext). Ensuite, choisissez **Analyser le texte...** dans le menu Outils et cliquez sur le bouton Compter. TeXstudio affichera le nombre de paragraphes (c'est-à-dire de mots) dans votre texte et fournira même une analyse de fréquence de termes spécifiques. Cette fonctionnalité peut être utile pour affiner le style d'écriture de manuscrits, par exemple en identifiant une utilisation excessive de mots transitoires comme "quoique".

## Gestion des citations avec Zotero et BibTeX

### Obtenir et configurer Zotero et le plugin Better BibTeX

BibTeX est un plugin pour Zotero qui améliore ses capacités de gestion de référence pour les utilisateurs de LaTeX. Il fournit des outils pour générer, gérer et personnaliser les entrées BibTeX et BibLaTeX, ce qui en fait un outil de citation précieux dans les environnements LaTeX. BibTeX offre plusieurs fonctionnalités qui en font un choix privilégié :

- La gestion des clés de citation permet une génération de clés de citation personnalisée, offrant plus de contrôle sur le formatage des clés.
- L'exportation automatique et la mise à jour continue des exportations de BibTeX et de BibLaTeX garantissent que la bibliographie est toujours synchronisée avec la bibliothèque Zotero.
- La manipulation de caractères spéciaux empêche les erreurs BibTeX / BibLaTeX.
- Citer sous forme d'écriture pour TeX (par exemple TeXstudio) et même pour les éditeurs Markdown.


Pour installer Better BibTeX pour Zotero, suivez les étapes suivantes :

1. Assurez-vous que la dernière version de Zotero est installée sur votre système. Vous pouvez le télécharger à partir du [Zotero website](https://www.zotero.org).

2. Télécharger BibTeX:
- Allez au dépôt officiel [Better BibTeX GitHub](https://github.com/retorquere/zotero-better-bibtex).
- Téléchargez la dernière version du plugin -- assurez-vous de choisir le fichier `.xpi` de la version tardive.

3. Installez le plugin dans Zotero:
- Ouvrez Zotero
- Dans Zotero, accédez à *Tools* dans le menu supérieur et sélectionnez *Add-ons*
- Dans le gestionnaire Add-ons, cliquez sur l'icône de vitesse dans le coin supérieur droit et choisissez *Installer Add-on From File*
- Localisez le fichier `.xpi` téléchargé et cliquez sur *Open* - Zotero installera le plugin.
- Redémarrer Zotero pour activer le plugin.

4. Configurer BibTeX :
- Après l'installation, vous trouverez les paramètres Better BibTeX dans le menu Préférences Zotero (Windows) ou Paramètres (Linux) sous l'onglet *Better BibTeX*.
- Configurez votre format clé de citation et vos préférences d'exportation en fonction de votre workflow; notre recommandation:
     ```
     auth.lower + year + shorttitle(1,1).lower
     ```

5. Exportation et utilisation:
- Pour exporter une bibliographie, sélectionnez les références souhaitées dans Zotero, faites un clic droit et choisissez *Exporter des éléments*
- Sélectionnez *Better BibTeX* comme format d'exportation ; notez que le *Better BibLaTeX* peut ne pas produire la fonctionnalité souhaitée et provoquer des messages d'erreur intraçables lors de la compilation d'un fichier `.tex`.
- En option, cochez la case *maintenir à jour* dans la fenêtre suivante

For the domains of water resources reasearch and hydraulic engineering, you may want to work with our hydro-informatics.com library: [https://www.zotero.org/groups/4917569/hydro-informatics/library](https://www.zotero.org/groups/4917569/hydro-informatics/library).

### Fusion automatique de plusieurs duplicates

La fusion des duplicata dans Zotero peut se faire par un clic de souris, mais seulement par un clic de souris et élément par élément. Cela peut prendre beaucoup de temps lors de la fusion de grandes bibliothèques. Voici une solution pour fusionner automatiquement plusieurs duplicatas dans Zotero.

```{admonition} Make sure all duplicates have the same Item Type
:class: important

Pour faire fonctionner le code de fusion automatique suivant en douceur, passez par-dessus vos éléments dupliqués et recherchez tous les duplicatas marqués qui ont différents types d'éléments. Ensuite, harmoniser les types d'articles des paires dupliquées (c.-à-d. modifier le type d'article de l'une des entrées concernées). Ceci est un peu fastidieux, mais ne prend pas trop de temps et beaucoup plus vite que de fusionner chaque duplicata en plus par clic de souris.
```

* Ouvrez l'application Zotero sur votre ordinateur (pas dans le navigateur)
* Allez à l'entrée **Dupliquer des éléments** de votre bibliothèque
* Mettre tout en avant (pressez `CTRL` et `A` clés)
* Aller à **Outils** (menu supérieur) > **Développeur** > **Déplacer le JavaScript**, copier-coller le bloc de code suivant dans le champ **Code** et cliquer sur **Déplacer**


```
var DupPane = Zotero.getZoteroPanes();

for(var i = 0; i < 999; i++) {
  try {
    await new Promise(r => setTimeout(r, 50));
    DupPane[0].mergeSelectedItems();
    Zotero_Duplicates_Pane.merge();
  } catch (e) {
    console.log(e);
  }
}
```

Le bloc de code fait au maximum 999 itérations, qui peut être augmenté en augmentant le numéro d'itération dans la boucle du code JavaScript.


Cette réponse s'inspire des discussions du [Zotero Forum](https://forums.zotero.org/discussion/40457/merge-all-duplicates).

## Bibliographie

Lorsque vous travaillez avec LaTeX, la gestion de la bibliographie implique généralement l'utilisation d'un fichier .bib qui contient toutes vos références, que vous citez dans le document `.tex` en utilisant les commandes `\cite{...}` (ou similaires). Pour transformer ces citations et références en une bibliographie bien formatée, lancez un outil comme BibTeX après avoir compilé votre document LaTeX. ** Notez que TexStudio effectue ces itérations automatiquement pendant la compilation**, donc ces descriptions n'expliquent que pourquoi vous pouvez voir le processus de compilation redémarrer plusieurs fois, même si vous n'avez appuyé qu'une fois sur le bouton "Compiler".

BibTeX lit le fichier `.aux` d'une compilation précédente du document `.tex`, localise les entrées pertinentes dans le fichier `.bib`, puis crée un fichier `.bbl` contenant seulement les références citées, maintenant formaté selon les règles de style définies par un fichier de style de bibliographie (par exemple, un fichier `.bst` lors de l'utilisation de BibTeX). Ces fichiers de style contrôlent l'apparence et la disposition des citations et des références, y compris la façon dont les auteurs, les titres et les noms de revues sont affichés. Une fois le fichier `.bbl` généré, LaTeX l'intègre dans le document PDF final lors de la prochaine compilation. Le fichier `.bbl` est donc un sous-ensemble entièrement formaté de la base de données `.bib`, s'assurant que le document PDF affiche uniquement les références effectivement citées, arrangées et façonnées selon les lignes directrices de formatage choisies.

Pour gérer votre base de données de référence et générer un fichier `.bib`, nous vous recommandons d'utiliser des outils comme [Zotero](https://www.zotero.org/) (avec des conseils supplémentaires dans la section {ref}`Zotero Tips <debug-zotero>`). Notre [LaTeX thesis template](https://github.com/Ecohydraulics/latex-thesis-template) fournit plus de conseils sur le travail avec Zotero et la gestion du fichier `.bib`.
