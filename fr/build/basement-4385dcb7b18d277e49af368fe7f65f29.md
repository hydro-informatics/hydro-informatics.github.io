# BASE

```{admonition} Old BASEMENT versions, BASEMD, and BASEHPC
:class: important

La version 2 (v2) de BASE a été développée avec des structures complexes et un large éventail de capacités, mais l'accent a été mis peu sur le temps de calcul. La version 3 (v3) de BASE a considérablement simplifié le processus de modélisation pour les utilisateurs et est venue avec des options informatiques très efficaces, y compris la parallélisation massive sur les GPU. Toutefois, le v3 simplifié manque de nombreux modules pertinents, comme les lits de rivière multicouches pour calculer le changement topographique en fonction des formules de transport par charriage multigrains. Maintenant, la version 4 de BASEMENT (v4) fournit à la fois les capacités multiples de v2 sous forme de configurations de BASEMD, et l'efficacité de calcul de v3 sous forme de configurations de BASEHPC. Ce tutoriel explique la configuration d'un modèle BASEHPC.

```

Ce chapitre guide la mise en place d'une simulation numérique bidimensionnelle (2d) avec le logiciel gratuitement disponible BASE développé à l'ETH Zurich (Suisse). Visitez leur [site Web](https://basement.ethz.ch/) pour télécharger le programme et lire la documentation détaillée. Ce tutoriel comprend :

* Mise en place d'un modèle 2d hydrodynamique et stable
* Effectuer une simulation numérique 2d hydrodynamique constante
* Post-traitement des résultats de simulation : Visualiser, comprendre et analyser les sorties des modèles.

```{admonition} Requirements
:class: attention
Pour compléter ce tutoriel, il faut :

* L'installation de {ref}`qgis-install`.
* L'installation de [BASEMENT v4.0.1](https://basement.ethz.ch/) ou plus récent.
* Facultatif : [ParaView](https://www.paraview.org/).
```

```{admonition} Platform compatibility
:class: tip
Toutes les applications logicielles présentées dans ce tutoriel sont **compatibles avec les plateformes Linux et Windows**. Notez que la base est **non** disponible **pour macOS**.
```
