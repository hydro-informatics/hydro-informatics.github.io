(gdal)=
## OSGeo et GDAL y compris ogr et osr

La bibliothèque [gdal](https://gdal.org/) pour {ref}`raster data handling <raster>` vient avec [ogr](https://gdal.org/faq.html?highlight=ogr) pour {ref}`vector data handling <vector>`, et [osr](https://gdal.org/python/osgeo.osr-module.html) pour le référencement géospatial. GDAL et OGR sont gérés et développés par le [OSGeo Project](http://www.osgeo.org/), qui fait partie de la Fondation géospatiale Open Source - les développeurs de {ref}`qgis-install`.

Les didacticiels de ce livre électronique s'appuient sur `gdal` et `ogr` (y compris `osr` pour le référencement spatial), c'est pourquoi il est important d'obtenir l'installation de `GDAL` à droite :

* **Les utilisateurs de Linux** peuvent suivre les instructions pour installer `gdal` et [flusstools](https://flusstools.readthedocs.io) avec {ref}`pip and venv <pip-env>`.
* **Les utilisateurs de Windows** installent de préférence `gdal` et [flusstools](https://flusstools.readthedocs.io) dans un {ref}`conda environment <conda-env>` via Anaconda.


Sélectionnez votre plateforme pour des instructions d'installation plus spécifiques:

`````{tab-set}
````{tab-item} Linux / pip

GDAL nécessite l'installation de sudo. Trouvez plus de détails dans le {ref}`Python installation instructions <pip-env>` de ce livre électronique.

````

````{tab-item} Windows / conda
Pour installer `GDAL` pour Python par {ref}`Anaconda Prompt <install-pckg>` entrer:

```python
conda install -c conda-forge gdal
```
````
`````

````{admonition} Import GDAL, ogr, and osr from OSGeo
:class: important

L'importation de `gdal`, `ogr` et `osr` directement (p. ex., `import gdal`) est dépréciée depuis GDAL v3. Par conséquent, `gdal`, `ogr` et `osr` doivent être importées de `osgeo`:

```python
from osgeo import gdal
from osgeo import osr
from osgeo import ogr
```
````

## Descartes Labs
Even though of proprietary origin, the [`descarteslabs`](https://docs.descarteslabs.com/api.html) library (developed and maintained by [Descartes Labs](https://www.descarteslabs.com/)) comes with many open-sourced functions. Moreover, Descartes Labs hosts the showcase platform [GeoVisual Search](https://search.descarteslabs.com/) with juicy illustrations of artificial intelligence (AI) applications in geoscience. Note that `descarteslabs` is not installed along with [flusstools](https://flusstools.readthedocs.io).

`````{tab-set}
````{tab-item} Linux / pip
Pour installer `descarteslabs`, ouvrez Terminal et tapez :

```python
pip install descarteslabs
```
````

````{tab-item} Windows / conda
Pour installer `descarteslabs` pour Python, ouvrez {ref}`Anaconda Prompt <install-pckg>` et tapez :

```python
conda install -c conda-forge descartes
```

Si l'installation échoue, essayez ce qui suit :

```python
conda install shapely
pip install descarteslabs
```
````
`````

## Python Imaging Library (PIL) / oreiller
Le traitement des images avec Python est activé avec la bibliothèque d'imagerie de Python* (*PIL*). *PIL* prend en charge de nombreux formats de fichiers d'images et possède des capacités de traitement graphiques efficaces. La bibliothèque `pillow` est une fourche facile à utiliser *PIL* et fournit des modules `Image*` (p. ex., `Image`, `ImageDraw`, `ImageMath`, et bien d'autres). Si [flusstools](https://flusstools.readthedocs.io) est installé, aucune autre action n'est requise pour travailler avec le contenu relatif à *PIL*/*pillow* de ce livre électronique.

Note that the `conda base` environment includes `PIL` (test with `import PIL`), which needs to be uninstalled before installing `pillow`. For installing *PIL*/*pillow*, refer to [https://pillow.readthedocs.io](https://pillow.readthedocs.io/en/stable/installation.html).

## Autres colis

Outre les paquets susmentionnés, il existe d'autres bibliothèques utiles pour les analyses géospatiales avec Python (**`Packages in bold red font`** sont installées avec [flusstools](https://flusstools.readthedocs.io)):

* [**`alphashape`**](https://pypi.org/project/alphashape/) crée des polygones liés contenant un ensemble de points.
* [django](https://docs.djangoproject.com/en/3.0/ref/contrib/gis/) comme cadre Web géographique et pour les connexions à la base de données.
* [**`geopandas`**](https://geopandas.org/) permet l'application des opérations de base de données {ref}`pandas` aux ensembles de données géospatiales.
* [NetworkX](https://networkx.github.io/documentation/stable/index.html) pour des analyses de réseau telles que trouver un chemin le moins cher / le plus court entre deux points.
* [owslib](http://geopython.github.io/OWSLib/) pour se connecter à *Open Geospatial Consortium* (OGC) services Web.
* [postgresql](https://www.postgresqltutorial.com/postgresql-python/) pour les connexions SQL.
* [**`rasterio`**](https://rasterio.readthedocs.io/en/latest/) pour le traitement des données de raster en tant que tableaux {ref}`numpy`.
* [**`rasterstats`**](https://pythonhosted.org/rasterstats/) produit des statistiques zonales des rasters et peut interagir avec les fichiers {ref}`geojson`.
* [**`sckit-image`**](https://scikit-image.org/) pour l'apprentissage automatique appliqué aux images géoréférencées.
