# hyhome — hydro-informatics.com Source

## Environment

- **Mamba environment**: `hywebv2`
- Always use `mamba run -n hywebv2` to run Python, pip, or Jupyter Book commands in this project.

## Build commands (Jupyter Book v2)

| Goal | Command |
|------|---------|
| Dev preview (live-reload) | `mamba run -n hywebv2 jupyter-book start` |
| Dev preview (headless) | `mamba run -n hywebv2 jupyter-book start --headless` |
| Static HTML for deployment | `mamba run -n hywebv2 jupyter-book build --html` |
| Any of the above + execute notebooks | add `--execute` |

The old JB v1 command `jupyter-book build .` does **not** work in v2 — the `.` is treated as a file path, not a project root.

## Workflow

This is the source for the Jupyter Book v2 site at hydro-informatics.com, configured via `myst.yml` and `_toc.yml`.
