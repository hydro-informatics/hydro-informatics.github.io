Bedload Exercise

For interactive reading and executing code blocks or , or download the notebook and install Python and JupyterLab locally to run bedload-exercise.ipynb on your own machine. The notebook on Binder, Colab and GitHub is the original French version of this page.

Important

The exercise consists of three files that must keep this folder structure. Do not download the zip file of the jupyter-python-course repository (it contains all notebooks and datasets of the course); download the three files one by one instead (on GitHub: Download raw file).

filecontents
bedload-exercise.ipynbthis notebook, the only file to edit
fun/charriage.pythe technical code: Meyer-Peter & Müller (MPM) formula, checks and figures
data/hecras-arbogne.csvthe hydraulics of 16 HEC-RAS 1D cross-sections of the Arbogne at Dompierre (FR) for Q = 25 m3^33/s
Challenge

Your expertise is requested to analyze the risk of aggradation in the restored reach of the Arbogne. A colleague has provided you with the (1D) hydraulics of 16 cross-sections over 890 m. Where does the gravel stop, and what happens when vegetation slows down the flow?

Structure of the Exercise¶

partwho does the work
Isetup: load the script and the datagiven: run the cells
IIdata: grain sizes, roughness coefficients kstk_{st}kst​, threshold τ∗,cr\tau_{*,cr}τ∗,cr​you: complete two lists
IIIequations: roughness ratio k′k'k′ and critical roughness kst,crk_{st,cr}kst,cr​you: complete two lines of code
IVresults: MPM bedload calculation, Shields diagram, active cross-sectionsgiven: run and interpret

Programming experience is not required. Run a cell with Shift + Enter. The spots to complete are marked with the comment # >>> À COMPLÉTER (to complete): replace each text ">>> COMPLETER" (quotes included) with your value or equation. In the code, decimal numbers are written with a point (0.047, not 0,047).

Note

The code is in French, like the notebook that Binder launches: variable and function names, comments and the messages printed by charriage.py. The names you will work with are melanges (grain mixtures), k_st (Strickler coefficients), tau_cr (critical Shields parameter), rapport_rugosite (roughness ratio) and k_st_critique (critical roughness).

Shields Diagram¶

The diagram compares the two roughness cases, without vegetation (flow in the channel) and with vegetation (flood overtopping into the floodplain), for both grain classes, gravel and sand. Every point is a cross-section. The vertical axis is the effective shear stress on the grains k′ τ∗k'\,\tau_*k′τ∗​, the one that MPM compares with τ∗,cr\tau_{*,cr}τ∗,cr​. Below the critical Shields curve, there is no bedload transport.

  • color: roughness case (blue without vegetation, red with vegetation);
