Virtuelle Maschinen und Linux

Ihr Computer ist einer Ihrer wichtigsten Bildungsbegleiter. Sie möchten also die Gesundheit Ihres Computers schützen und Probleme vermeiden, die durch redundante oder sogar bösartige Software verursacht werden. Aus diesem Grund wird empfohlen, alle auf dieser Website verwendeten Software auf einer sogenannten Virtual Machine (VM) zu installieren. Diese Seite erklärt, was VMs sind, welche Vorteile sie genau haben und wie Sie Debian Linux, eines der stabilsten und sichersten Betriebssysteme] installieren können. Es spielt keine Rolle, ob Sie Apples *mac OS * oder Microsofts *Windows * verwenden oder ob Sie bereits Linux verwenden: Die VM sieht am Ende gleich aus.

Über¶

Was ist eine virtuelle Maschine (VM)?¶

Eine virtuelle Maschine (VM) stellt ein virtuelles Betriebssystem (OS) dar, das auf einem Hostsystem ausgeführt wird, das direkt auf einem physischen Computer ausgeführt wird. Die physischen Computer- (Hardware-)Ressourcen des Host-Systems werden über sogenannte Hypervisoren vergeben. Aus diesem Grund wird die virtuelle Maschine als *Gastmaschine * und der Hypervisor als *Hostmaschine * bezeichnet. Eine Gastmaschine ist also eine isolierte, virtualisierte Umgebung, die unabhängig auf dem Host-Betriebssystem läuft.

Warum eine VM verwenden?¶

Kostenlose Ressourcen auf einem Computer stellen aus wirtschaftlicher Sicht toten Speicherplatz dar, der Kosten verursacht, ohne Einnahmen zu generieren. Aus diesem Grund erstellen Systemadministratoren häufig mehrere virtuelle Server, um physische Ressourcen besser zuzuweisen und Energie zu sparen. Eine VM ist auch für intelligente Endnutzer wie Forscher und Ingenieure nützlich. Hier sind einige Vorteile einer VM:

  • Anwendungen und Dienste mehrerer VMs stören sich nicht gegenseitig.

  • Unabhängigkeit des Gastsystems vom Betriebssystem des Hostsystems und der physischen Hardware.

  • VMs können verschoben oder geklont werden, indem sie einfach auf andere Systeme kopiert werden.

  • Hardware-Ressourcen können dynamisch über den Host-Hypervisor zugewiesen werden.

  • Bessere und effizientere Nutzung vorhandener Hardwareressourcen.

  • Kurze Bereitstellungszeiten für Systeme und Anwendungen, die auf einer VM laufen.

  • VMs bieten hohe Verfügbarkeit und Flexibilität aufgrund ihrer Unabhängigkeit von physischen Ressourcen.

Im Rahmen der Hydroinformatik für das Wasserressourcenmanagement kann eine VM dazu dienen, verschiedene * Python * Skripte mit unterschiedlichen Abhängigkeiten auszuführen oder vor allem eine saubere und effiziente Umgebung für die Ausführung numerischer Modelle wie open TELEMAC-MASCARET] einzurichten.

This tutorial provides guidance on creating a new VM, re-using an existing VM, and working with Debian Linux on a VM.

Inhalt und Debian Linux¶

Diese Seite führt durch die Installation einer Debian Linux virtuellen Maschine]. Der Host-Hypervisor wird als Oracles VirtualBox auf Windows] angenommen. Wenn Sie Windows nicht verwenden, laden Sie einfach das VirtualBox-Installationsprogramm herunter, das zu Ihrem System passt. Während VirtualBox x-platform funktioniert, gibt es andere, leistungsstärkere plattformspezifische Dienstprogramme zum Erstellen von VMs:

GNOME boxes(Linux)
UTM app (mac / iOS)
sudo apt install gnome-boxes
sudo apt install virt-manager qemu-kvm libvirt-daemon-system

UTM] ist eine kostenlose Open-Source-VM-Anwendung für macOS (und iOS), mit der Sie Windows, Linux und andere Betriebssysteme auf einem Mac ausführen können. Es verwendet das Hypervisor-Framework von Apple, um ARM64-Systeme auf *Apple Silicon * mit nahezu nativen Geschwindigkeiten auszuführen, während es auch die Emulation für x86/x64 und über 30 andere Prozessorarchitekturen über sein QEMU-Backend unterstützt. UTM ist völlig kostenlos ohne Funktionseinschränkungen, was es zu einer zugänglichen Wahl für alle macht, die Software auf verschiedenen Plattformen testen müssen.

Auf dem Gastcomputer läuft Debian Linux, eine der stabilsten Linux-Distributionen, und er ist frei verfügbar. Aufgrund seiner Stabilität ist Debian eine ideale Basis für numerische Simulationen, die Tage oder sogar Wochen dauern können. Natürlich gibt es andere Optionen, und Debian ist eher eine der besten Optionen als die beste Option.

Es gibt ein paar Debian Linux Spin-offs, wie Ubuntu] mit einigen anderen Derivaten, die leichter (und schneller) sind. Neue Linux-Benutzer haben einen einfachen Start mit den Ubuntu-Varianten Linux Mint (Xfce) oder Lubuntu]. Die meisten Versionen Ubuntu können anstelle des hier vorgestellten Debian Linux verwendet werden, um die Tutorials auf dieser Website abzuschließen.

    • VirtualBox-Installer sind für Windows, mac OS (einschließlich Apple Silicon über den dedizierten ARM-Build) und Linux-Hosts verfügbar.

  • Laden Sie das neueste Debian Linux (oder eines seiner Spin-offs - siehe nächster Aufzählungspunkt) Net Installer herunter (dies ist die **empfohlene ** Lösung **für ** Arbeit mit **TELEMAC **):

    • Die aktuelle stabile Version ist Debian 13 (Codename trixie).

    • Finden Sie den CD-Abschnitt und klicken Sie auf die amd64 Version]

    • Scrollen Sie zum Ende der Seite und laden Sie das neueste Netzinstaller herunter (z.B. debian-13.x.x-amd64-netinst.iso)

    • Wenn der obige Link nicht funktioniert, besuchen Sie debian.org, finden Sie den Abschnitt Debian erhalten (klicken Sie nicht auf den Abschnitt im oberen Menü), klicken Sie auf CD/USB ISO-Bilder und klicken Sie auf CD/DVD-Bilder mit HTTP herunterladen].

  • ISO-Bilder für Debian-Spin-offs können auch verwendet werden, um die Tutorials auf dieser Website abzuschließen (Allround-Systeme):

Denken Sie daran, wo die heruntergeladene Linux *.ISO * Datei gespeichert ist.

Erstellen einer VM mit VirtualBox¶

Geschätzte Dauer: 5-8 Minuten.

Klicken Sie in Ihrem Hostsystem (z. B. Windows 11) auf Start, geben Sie Oracle VM VirtualBox ein und drücken Sie auf Enter. Im geöffneten VirtualBox Managerfenster:

  • Klicken Sie auf die blaue Schaltfläche Neu, um den VM-Erstellungsassistenten zu öffnen und geben Sie ein:

    • Name: Debian Linux
      * Hinweis: Der Assistent sollte die * Typ * und * Version * Felder automatisch erkennen. *

    • *Maschinenordner: C:\Users\USERNAME\VirtualBox VMs

    • Typ: Linux

    • Version: Debian (64-bit)
      > Klicken Sie auf den Button Next

    • Speichergröße zuweisen: Je mehr Speicher der VM zugewiesen wird, desto schneller wird die VM (und zum Beispiel TELEMAC-MASCARET), desto langsamer wird das Hostsystem (Windows 11). Faustregel: Bleiben Sie im grünen Bereich der Bar (z. B. 8192 MB oder mehr zuweisen)
      Klicken Sie auf den Button Next

    • Wählen Sie Jetzt eine virtuelle Festplatte erstellen und klicken Sie auf die Schaltfläche Erstellen.

    • Wählen Sie VDI (nativ zu VirtualBox) und klicken Sie auf Weiter.

    • Wählen Sie vorzugsweise * Dynamisch zugewiesen*, um mit einer kleinen virtuellen Festplattengröße zu beginnen, die eine maximale Größe annehmen kann, die im nächsten Schritt definiert wird. Klicken Sie auf den Button Next.

    • Lassen Sie den Standard-Disk-Namen so, wie er ist, und weisen Sie der virtuellen Festplatte eine maximale Größe zu (empfohlen: mindestens 32 GB). Klicken Sie auf den Button Erstellen.

  • Großartig - die grundlagen sind jetzt alle eingestellt und wir sind wieder im * virtualbox * hauptfenster, wo eine * debian linux * vm jetzt auf der linken seite des fensters sichtbar sein sollte.

  • Wenn die *Debian Linux * VM hervorgehoben ist (d. H. Klicken Sie einfach darauf), klicken Sie auf die gelbe * Einstellungen * Radtaste, die das * Einstellungen * Fenster öffnet:

    • Überprüfen Sie auf der Registerkarte System/Motherboard die Speicherzuweisung und aktivieren Sie das Feld Enable EFI (nur spezielle Betriebssysteme) (aktivieren).

    • Wählen Sie auf der Registerkarte System/Prozessor die Anzahl der Prozessoren aus, die die VM verwendet. Um das Hostsystem nicht zu verlangsamen (Windows 11), bleiben Sie im grünen Bereich der CPU-Leiste. Für die parallele Verarbeitung mit TELEMAC-MASCARET mindestens 4 CPUs zuweisen.

    • Aktivieren Sie auf der Registerkarte Display das Feld Enable 3D Acceleration.

    • Auf der Registerkarte Storage finden Sie den Controller: IDE, wo sich unten ein Empty Festplattensymbol befinden sollte.

      • Klicken Sie auf das Symbol Empty und finden Sie den Rahmen Attributes auf der rechten Seite des Fensters, wo ein kleines blaues Symbol sichtbar sein sollte.

      • Klicken Sie auf das kleine blaue Festplattensymbol, um eine Festplattendatei auszuwählen ... > Wählen Sie das Debian Linux-Netzinstaller (z. B. debian-13.x.x-amd64-netinst.iso), das Sie zuvor heruntergeladen haben.

    • Klicken Sie auf OK.

Debian Linux installieren¶

Geschätzte Dauer: 30 Minuten.

Um Debian Linux auf der VM zu installieren, starten Sie die zuvor erstellte Debian Linux VM im VirtualBox Managerfenster (klicken Sie auf die Debian Linux VM und dann auf den grünen Start Pfeil). Das VirtualBox VM-Fenster fordert die Verwendung der .iso-Datei auf (bestätigen Sie die ausgewählte Datei) und navigieren Sie durch die Installation:

  • Wählen Sie im Fenster *VirtualBox VM * die Option *Grafische Installation * aus.

  • Navigieren Sie durch die Sprachoptionen (empfohlen: Englisch - Englisch (USA)).

  • Definieren Sie optional einen Hostnamen (z.B. debian-vm) und einen Domainnamen (z.B. debian-net).

  • Erstellen Sie einen Root-Benutzernamen und ein Passwort (schreiben Sie die Anmeldeinformationen irgendwo auf) sowie einen Benutzernamen (keine Root-Rechte) und ein Passwort.

  • Stellen Sie die Uhr ein.

  • Festplattenpartitionierung: Wählen Sie die Option * Geführt - Verwenden Sie die gesamte Festplatte *. Klicken Sie auf *Weiter * (2 mal).

  • Wählen Sie die Option *Alle Dateien in einer Partition (für neue Benutzer empfohlen) * aus. Klicken Sie auf Weiter.

  • Stellen Sie sicher, dass Partitionierung beenden und Änderungen auf Festplatte schreiben ausgewählt ist, und klicken Sie auf *Weiter *.

  • Wählen Sie im nächsten Schritt Ja aus (Änderungen auf Festplatten schreiben?).
    ... schnappen Sie sich Ihr Lieblingsgetränk und warten Sie, bis die Installation fortschreitet ...

  • Wählen Sie Nein aus, um die Frage Eine andere CD oder DVD scannen? und klicken Sie auf Weiter.

  • Wählen Sie den geografisch nächstgelegenen Spiegel aus, um auf Debian-Archive (Software-Repositories und Updates) zuzugreifen, und klicken Sie auf *Weiter * (2 Mal).

  • Überspringen sie die proxy-informationsfrage (klicken sie einfach * weiter *).

  • Wählen Sie optional Nein aus, um die Frage Teilnehmen Sie an der Umfrage zur Paketnutzung? zu beantworten, und klicken Sie auf Weiter.

  • Installierte Software: Wählen Sie GNOME (Standard-Debian-Desktop) und behalten Sie die anderen Standardeinstellungen (Debian-Desktop, Druckserver und Standardsystemprogramme). Seit Debian 12 aktiviert das Installationsprogramm standardmäßig auch die non-free-Firmware-Komponente, die Debian 13 (Trixie) als erstklassige Repository-Komponente für Hardwaretreiber behandelt.
    ... genießen Sie weiterhin Ihr Lieblingsgetränk und warten Sie, bis die Installation fortschreitet ...

  • Klicken Sie auf Weiter, um die Installation abzuschließen und die VM neu zu starten (oder herunterzufahren).

Sobald die VM heruntergefahren ist, öffnen Sie die VM * Einstellungen * wieder (aus dem Fenster * VirtualBox Manager *) und gehen Sie zur Registerkarte * Speicher *. Stellen Sie sicher, dass sich im Feld Controller: IDE wieder ein Empty Festplattensymbol befindet.

Wiederverwendung (Export/Transfer oder Kopie) eines VM auf einem anderen Host¶

Once you have created a VM on a virtual hard disk (the *.vdi file), you can always transfer it to another host system with its ecosystem. To copy (or transport) the VM:

  • Auf dem ursprünglichen Host:

    • Schließen Sie die VM, die Sie wiederverwenden möchten.

    • Gehen Sie in VirtualBox zu File > Export Appliance....

    • Follow the instructions to export the VM to a *.ova file (the export process may take 10-15 minutes).

  • Auf dem neuen Host:

    • Stellen Sie sicher, dass VirtualBox installiert ist.

    • Kopieren Sie die exportierte *.ova-Datei in das neue Hostsystem.

    • Öffnen Sie VirtualBox und gehen Sie zu File > Import Appliance...

    • Navigieren Sie zu dem Verzeichnis, in dem Sie die *.ova-Datei kopiert haben.

    • Klicken Sie auf Weiter.

    • Überprüfen Sie die **Appliance-Einstellungen ** und klicken Sie auf **Import **.

Nun sollte die virtuelle Maschine in der Liste der virtuellen Maschinen in VirtualBox sichtbar sein.

Importieren eines vorhandenen VM in Oracle VM VirtualBox¶

Anstatt eine neue VM von Grund auf neu zu erstellen, können Sie eine bestehende VM in Oracle VM VirtualBox importieren. Dies ist nützlich, wenn eine VM bereits mit dem erforderlichen Betriebssystem, der Software, den Einstellungen und der Benutzerumgebung konfiguriert wurde.

Bestehende VMs werden üblicherweise in einem der folgenden Formate bereitgestellt:

  • eine Appliance-Datei, typischerweise .ova oder .ovf

  • ein virtuelles Festplattenabbild, wie .vdi, .vmdk oder .vhd

Das Importverfahren hängt vom Dateityp ab.

Ein VM-Gerät importieren¶

Make sure that Oracle VM VirtualBox is installed, as described in the VM requirements. Then open VirtualBox and:

  • Gehen Sie zu File > Import Appliance...

  • Wählen Sie die Datei .ova oder .ovf aus.

  • Klicken Sie auf Weiter.

  • Überprüfen Sie die Geräteeinstellungen, einschließlich:

    • VM-Name

    • Basisordner

    • CPU-Zuweisung

    • RAM-Zuweisung

    • Einstellungen für Netzwerkadapter

    • Ort der virtuellen Festplatte

  • Passen Sie die Einstellungen bei Bedarf an.

  • Klicken Sie auf Finish oder Import.

Nach dem Import sollte die VM in der Liste der verfügbaren VMs in VirtualBox erscheinen.

Registrieren Sie eine bestehende virtuelle Festplatte¶

Wenn die VM als virtuelles Festplattenimage und nicht als Appliance bereitgestellt wird, erstellen Sie eine neue VM und fügen Sie die vorhandene Festplatte an:

  • Klicken Sie auf New in VirtualBox.

  • Geben Sie einen VM-Namen ein.

  • Wählen Sie den entsprechenden OS-Typ und die entsprechende Version aus.

  • Zuweisung von RAM- und CPU-Ressourcen.

  • Wenn Sie zu einer Festplatte aufgefordert werden, wählen Sie **Verwenden Sie eine vorhandene virtuelle Festplatte **.

  • Wählen Sie die Datei .vdi, .vmdk oder .vhd.

  • Beenden Sie das VM-Setup.

Bevor Sie die VM starten, überprüfen Sie die VM-Einstellungen und passen Sie sie bei Bedarf an.

Starten und Konfigurieren der importierten VM¶

Nach dem Importieren oder Registrieren der VM starten Sie sie im Hauptfenster der VirtualBox. Überprüfen Sie beim ersten Start die folgenden Elemente:

  • Keyboard Layout: Stellen Sie sicher, dass das Gastbetriebssystem das erwartete Tastaturlayout verwendet.

  • Anmeldeinformationen: Verwenden Sie die mit der VM-Dokumentation bereitgestellten Anmeldeinformationen.

  • Netzzugang: Überprüfen Sie, ob die VM NAT, Bridged Networking oder einen anderen Netzwerkmodus verwendet.

  • Anzeigeeinstellungen: Einstellen der Bildschirmauflösung und -skalierung, falls erforderlich.

  • **Gastzusätze **: Installieren oder aktualisieren Sie VirtualBox Guest Additions, wenn freigegebene Zwischenablage, dynamische Größenänderung oder Ordnerfreigabe nicht funktionieren.

  • System-Updates: Wenn das Gastbetriebssystem Paketupdates unterstützt, aktualisieren Sie es, bevor Sie zusätzliche Software installieren.

  • Shared folders: To exchange files between the host and guest systems, configure shared folders as described in folder sharing.

Für Linux-Gäste können Systemupdates in der Regel vom grafischen Update-Manager oder vom Terminal aus gestartet werden. Verwenden Sie für Debian- oder Ubuntu-basierte Systeme:

sudo apt update
sudo apt full-upgrade
sudo apt autoremove

Empfohlene VM-Einstellungen¶

Bevor Sie die VM für größere Berechnungen oder Softwareinstallationen verwenden, überprüfen Sie die folgenden Einstellungen:

  • RAM: Weisen Sie genügend Speicher für das Gastbetriebssystem und die Gastanwendungen zu, lassen Sie jedoch ausreichend RAM für das Hostsystem.

  • CPU: Weisen Sie mehrere CPU-Kerne nur zu, wenn das Hostsystem über genügend Ressourcen verfügt.

  • **Speicherung **: Stellen Sie sicher, dass die virtuelle Festplatte genügend freien Speicherplatz hat.

  • Netzwerk: Verwenden Sie NAT für einfachen Internetzugang oder überbrückte Netzwerke, wenn die VM im lokalen Netzwerk sichtbar sein muss.

  • Schnappschüsse: Erstellen Sie einen Snapshot vor größeren Updates oder Konfigurationsänderungen.

Mit einem Snapshot können Sie zu einem früheren VM-Status zurückkehren, wenn ein Aktualisierungs-, Installations- oder Konfigurationsschritt fehlschlägt.

Debian Linux¶

Setup Linux¶

Geschätzte Dauer: 15 Minuten.

Starten Sie die *Debian Linux * VM aus dem *VirtualBox * Managerfenster. Sobald Debian Linux gestartet ist, melden Sie sich mit Ihren Benutzerinformationen an.

Um die volle Funktionalität des Systems zu aktivieren, öffnen Sie das Linux-Terminal (CTRL + Alt + T) oder gehen Sie zu Aktivitäten > Akten (Archivsymbol), klicken Sie mit der rechten Maustaste auf einen beliebigen Ordner und wählen Sie Im Terminal öffnen. In Terminal Typ:

su

Geben Sie das oben erstellte Passwort für den Root-Benutzernamen ein (siehe Abschnitt Installation).

Note

Root access (e.g., for installing software) is granted on many Linux distributions using the sudo command before the command to execute. In Debian Linux, sudo may refer to the wrong account and not work as desired. As a workaround type su in Terminal. Read more later in this section.

Installieren Sie alle Pakete, die zum Erstellen von Kernelmodulen erforderlich sind:

apt update
apt install build-essential dkms linux-headers-$(uname -r)

Suchen Sie das Dropdown-Menü Geräte des Fensters VirtualBox VM (nicht in Debian Linux selbst) und wählen Sie das CD-Image Insert Guest Additions... (je nach Version von VirtualBox kann sich dieses Menü oben oder unten im Fenster befinden).

Where is the Devices entry?

Das Fenster VirtualBox VM zeigt das Menü mit dem Eintrag Geräte nirgendwo an?

  • Dies kann passieren, wenn View auf Scaled mode gesetzt wurde.

  • Um den Ansichtsmodus umzuschalten und die Menüleiste sichtbar zu machen, drücken Sie die RIGHT CTRL (Host) Taste + die C auf Ihrer Tastatur, während Sie sich in der Hostsystemansicht befinden.

If the error The guest system has no CR-ROM ... occurs...

To troubleshoot the error message The guest system has no CR-ROM ..., shut down the VM. In the VirtualBox manager window, right-click on the Debian Linux VM > Storage tab > Add new Optical Drive to Controller: IDE. Restart the Debian Linux VM.

Zurück im Debian Linux *Terminal * mounten Sie die *Guest Additions * *iso * Datei, indem Sie *Terminal * eingeben:

sudo mkdir -p /mnt/cdrom
sudo mount /dev/cdrom /mnt/cdrom

Navigieren Sie zum eingebundenen Verzeichnis und führen Sie die Datei VBoxLinuxAdditions.run mit dem Flag --nox11 aus, um ein Xterm-Fenster zu vermeiden.

cd /mnt/cdrom
sudo sh ./VBoxLinuxAdditions.run --nox11

Die Kernel-Module werden jetzt installiert und Terminal sollte eine Nachricht auslösen, die Sie zum Neustart des Systems auffordert. Dies geschieht durch Eingabe:

shutdown -r now

Stellen Sie nach dem Neustart sicher, dass die Installation erfolgreich war. In Terminal Typ:

lsmod | grep vboxguest

The installation was successful if the Terminal’s answer is something like vboxguest 358395 2 vboxsf. Read more about Guest Additions on the VirtualBox developer’s website.

Um das visuelle Erlebnis zu verbessern, tun Sie Folgendes:

  • Klicken Sie in der oberen linken Ecke des Debian Linux Desktops auf *Aktivitäten * und geben Sie im Suchfeld *Anzeigen * ein.

  • Öffnen Sie die Einstellungen Displays, um eine bequeme Anzeigeauflösung auszuwählen.

    • Wenn Sie eine zu hohe Auflösung wählen, wird das Fenster *VirtualBox VM * schwarz und springt nach 15-30 Sekunden wieder auf die ursprüngliche Auflösung zurück.

    • Erwägen Sie auch, * Night Light * einzuschalten, um Ihr Augenlicht zu erhalten.

  • Anwenden der Änderungen und Schließen der Displays-Einstellungen.

Das GNOME Terminal ist eines der wichtigsten Features, auch wenn es am Anfang optisch nur ein leeres Fenster mit einem blinkenden Cursor zeigt. Es gibt viele Möglichkeiten, Terminal zu öffnen, und hier sind zwei Optionen:

  1. Gehen Sie zu *Anwendungen * und geben Sie * Terminal * in das Suchfeld ein, oder

  2. Öffnen Sie den File-Browser (Applications > Files - das Archivierungscontainersymbol), navigieren Sie zum Ordner, in dem Sie Terminal ausführen möchten, klicken Sie mit der rechten Maustaste auf den freien Bereich und mit der linken Maustaste auf Open in Terminal.

Es wird dringend empfohlen, das Tutorial der Ubuntu-Community (geschätzte Dauer: 51 Minuten)] durchzugehen, um einige Inhalte dieses eBooks besser zu verstehen. Insbesondere merken Sie sich die Befehle cd (Verzeichnis ändern), su/sudo (Superuser), ls (listen) und mkdir (Verzeichnis erstellen).

Benutzerrechte¶

When installing software later, it is good practice to install it for your user account and not for root. Such system-relevant actions require superuser (su) rights. However, your default user name is not on the so-called sudoers list, which is essentially a file where all user accounts are listed that are authorized to use sudo in front of any command. So add your user account to the su-doers list by opening Terminal and typing:

su
    password: ...
sudo usermod -aG sudo YOUR-USER-NAME

Öffnen Sie eine neue Registerkarte Terminal (Shift + CTRL + T), die sich in Ihrem Standardbenutzerbereich mit Standardbenutzerrechten öffnen sollte. Überprüfen Sie, ob Ihr Konto auf der * Sudoers * Liste steht, indem Sie eingeben:

sudo -v

If visually nothing happens, you are good to go. Otherwise, if you get a message like Sorry, user [username] may not run sudo on [hostname]., verify that you correctly typed the above command and YOUR-USER-NAME (with correct cases).

VM-Einstellungen¶

Aktivieren Sie den Ordneraustausch zwischen Host und Gast¶

Geschätzte Dauer: 5-10 Minuten.

Requirements

Stellen Sie sicher, dass Sie Guest Additions installieren, um die Ordnerfreigabe zu aktivieren (siehe den obigen Abschnitt Setup Linux).

Die gemeinsame Nutzung von Daten zwischen dem Hostsystem (z.B. Windows 11) und dem Gastsystem (Debian Linux VM) ermöglicht die Übertragung von Dateien zu und von der VM zum Hostsystem.

  • At a place of your convenience, create a new folder on the host system (e.g., Windows 11) and call it shared (e.g., C:\Users\USER\documents\shared\).

  • Start VirtualBox und Debian Linux VM.
    * Stellen Sie sicher, dass der skalierte Ansichtsmodus ausgeschaltet ist (Schalten Sie die Ansichtsmodi mit RIGHT CTRL (Host) und C auf der Tastatur).*

  • Gehen Sie zum VM *VirtualBox * Fenster *Geräte * Menü, klicken Sie auf *Geteilte Ordner * > Geteilte Ordner Einstellungen... und klicken Sie auf das kleine blaue Hinzufügen neuer freigegebener Ordner Symbol auf der rechten Seite des Fensters (siehe Abbildung unten). Führen Sie die folgenden Einstellungen im Pop-up-Fenster aus:

    • Folderweg: Wählen Sie den gerade erstellten ...\shared Ordner aus

Softwaremanagement¶

Geschätzte Dauer: Variabel.

Software installieren¶

Um andere Software zu installieren, verwenden Sie vorzugsweise den integrierten Software-Manager (Aktivitäten > Shopping Bag Symbol). Der Software-Manager verwendet offizielle Releases im stabilen Debian-Repository (lesen Sie mehr über Listen der Quellen].

Der letzte Befehl entfernt Dateien, die nicht mehr benötigt werden und reduziert den Systemmüll.

apt and apt-get

Being a new Linux end user, preferably use apt rather than apt-get. That means:

  • Verwende sudo apt install PACKAGE

  • ** Verwenden Sie nicht sudo apt-get install PACKAGE**

Still, you may need to use apt-get for some specific cases (e.g., if a package provider instructs particularly you to do so).

Anweisungen zur Installation bestimmter und Debian-kompatibler Software (z. B. QGIS) finden Sie direkt auf der Website der Softwareentwickler. Um beispielsweise Anaconda Python zu installieren, besuchen Sie docs.anaconda.com] und folgen Sie den Installationsanweisungen für Debian Linux.

Software minimalism: Less is better than more

Je mehr Software auf Ihrem Computer vorhanden ist, desto langsamer wird es sein und desto weniger Speicherplatz ist verfügbar. Wenn also der Hauptzweck Ihrer VM darin besteht, ressourcenintensive Simulationen durchzuführen (z. B. mit TELEMAC), vermeiden Sie die Installation anderer Software als der für die Ausführung des Modells erforderlichen.

The most popular software manager of Debian-based Linux distributions is called aptitude, which is the thing that you invoke when typing [sudo] apt [something]. There are more standard package managers, such as dpkg or synaptic (see the full list in the Debian package management faqs). To install a wide range of proprietary software (e.g., video conferencing tools), package management tools like snapd or flatpak can be useful. However, such third-party package managers are debated, and a more robust approach is to use apt whenever possible, or, if the software is not available through apt, look for AppImages.

Paket-Repositories hinzufügen¶

Für das Hinzufügen von (vertrauenswürdigen) Software- (Paket-)Repositories verwenden Sie software-properties-common, das den Befehl add-apt-repository bereitstellt:

sudo apt install software-properties-common

sudo add-apt-repository non-free

Note

Since Debian 13 (trixie), the default /etc/apt/sources.list.d/debian.sources file already ships with main and non-free-firmware. Only add contrib / non-free when you actually need a package that lives in those components.

Pakete suchen¶

Some software will run into errors because of missing library files (e.g., libGLX.so.0: No such file or directory). To find out what package needs to be installed for getting the missing library file, install apt-file

sudo apt install apt-file
sudo apt-file update

To find out the package name of a missing library file (e.g., libGLX.so.0), tap:

apt-file find libGLX.so.0

Nach ein paar Sekunden der Suche wird *apt-file * etwas wie:

libglx0-glvnd-nvidia: /usr/lib/x86_64-linux-gnu/libGLX.so.0

That means, to get the library file libGLX.so.0, the package libglx0-glvnd-nvidia must be installed; for instance:

sudo apt install libglx0-glvnd-nvidia

Um Repositories zu aktualisieren und installierte Pakete über apt zu aktualisieren, ist dies der Standard-Debian-Paketmanager aptitude, geöffnet Terminal und Typ:

sudo apt update
sudo apt full-upgrade
sudo apt autoremove
sudo apt autoclean

Dadurch werden die manuell installierte Software und die über snapd und flatpak] installierten Pakete nicht aktualisiert.

    • In the background. Terminal might prompt the message err:mscoree:LoadLibraryShim error reading registry key for installroot - you may ignore such messages (read more).

Never run wine as root (sudo).

Why? It is just not safe. So if you did run wine as root anyway, roll back with cd $HOME and tap sudo chown -R $USER:$USER .wine More information is available in the wine docs.

** Starten Sie eine Windows-Anwendung**, indem Sie wine explorer in Terminal eingeben. Wines Windows-Dateisystem wird in einem Windows-ähnlichen Fenster angezeigt. Zum Start und zur Anwendung:

  • Wenn während der Installation ein Desktop-Icon erstellt wurde, gehen Sie zu Desktop und doppelklicken Sie auf die Anwendung (z. B. BlueKenue).

  • Andernfalls identifizieren Sie den Installationspfad und die ausführbare Datei, die die Anwendung startet.

    • 32-bit programs are typically installed in "C:\\Program Files (x86)\\ (e.g., "C:\\Program Files (x86)\\CHC\\BlueKenue\\BlueKenue.exe").

    • 64-bit programs are typically installed in "C:\\Program Files\\.

  • Mit dem Installationspfad kann jede Windows-Anwendung über Terminal gestartet werden mit:

    • wine "C:\\path\\to\\the.exe" (verwenden Sie \\, um Unterverzeichnisse zu trennen).

    • For example, wine "C:\\Program Files (x86)\\CHC\\BlueKenue\\BlueKenue.exe" typically starts Blue KenueTM.
