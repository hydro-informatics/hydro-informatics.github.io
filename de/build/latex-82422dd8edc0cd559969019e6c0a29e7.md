# LaTeX & Citation Management (Zotero)

Online LaTeX-Editoren, wie Overleaf, bieten bequeme, Echtzeit-Kollaboration und Cloud-basierte Compilation, aber erweiterte Funktionen wie das Handling größerer Dokumente oder umfangreiche Team-Kollaboration erfordern oft ein bezahltes Abonnement. Im Gegensatz dazu können Sie vor Ort mit einem dedizierten Editor wie TeXstudio (siehe {ref}`LaTeX installation <install-tex>`) Dokumente bearbeiten und kompilieren, ohne dass eine Internetverbindung während des Schreibens/Verfassens und ohne Abokosten entsteht. Diese Seite soll eine Anleitung zur effektiven Nutzung von LaTeX in einer lokalen Umgebung bieten.


## Plaintext und Wortzählung

Um die Anzahl der Wörter in einem LaTeX Manuskript mit TeXstudio zu schätzen, beginnen Sie mit der Erstellung einer einfachen Textversion Ihres Dokuments. Wählen Sie im Menü **Tools** **Konvertieren Sie zu Abridged Plaintext***, der eine neue, unbetitelte Registerkarte mit Ihrem Text ohne LaTeX-Befehle öffnet. Diese abgestreifte Datei eignet sich auch zum Teilen mit Mitarbeitern, die (richtext) Wortprozessoren bevorzugen. Als nächstes wählen Sie **Analysetext...** aus dem Menü Tools und klicken Sie auf die Schaltfläche Zählen. TeXstudio wird die Anzahl der Absätze (d.h. Wörter) in Ihrem Text anzeigen und sogar eine Häufigkeitsanalyse bestimmter Begriffe liefern. Diese Funktionalität kann wertvoll sein, um den Schreibstil der Handschrift zu verfeinern, beispielsweise indem man eine Übernutzung von Übergangswörtern wie "wie immer" identifiziert.

## Citation Management mit Zotero und besser BibTeX

### Zotero und das Better BibTeX Plugin erhalten und einrichten

Better BibTeX ist ein Plugin für Zotero, das seine Referenz-Management-Funktionen für LaTeX-Benutzer verbessert. Es bietet Tools für die Generierung, Verwaltung und Anpassung von BibTeX- und BibLaTeX-Einträgen, so dass es ein wertvolles Zitationstool innerhalb von LaTeX-Umgebungen. Better BibTeX bietet mehrere Funktionalitäten, die es zu einer bevorzugten Wahl machen:

- Citation-Schlüsselverwaltung ermöglicht individuelle Zitationsschlüssel-Generierung, bietet mehr Kontrolle über Schlüsselformatierung.
- Automatische Exporte und fortlaufend aktualisierte BibTeX- und BibLaTeX-Exporte sorgen dafür, dass die Bibliographie immer mit der Zotero-Bibliothek synchronisiert ist.
- Handhabung von Sonderzeichen verhindert BibTeX / BibLaTeX Fehler.
- Cite-as-you-write-Unterstützung für TeX (z.B. TeXstudio) und sogar Markdown-Editoren.


Um Better BibTeX für Zotero zu installieren, folgen Sie diesen Schritten:

1. Stellen Sie sicher, dass Sie die neueste Version von Zotero auf Ihrem System installiert haben. Sie können es von der [Zotero website](https://www.zotero.org).

2. Bessere BibTeX herunterladen:
- Gehen Sie zum offiziellen [Better BibTeX GitHub repository](https://github.com/retorquere/zotero-better-bibtex).
- Laden Sie die neueste Version des Plugins herunter -- stellen Sie sicher, die `.xpi`-Datei der späten Version zu wählen.

3. Installieren Sie das Plugin in Zotero:
- Open Zotero
- In Zotero, navigieren Sie auf *Tools* im oberen Menü und wählen Sie *Add-ons*
- Klicken Sie im Add-ons Manager auf das Zahnrad-Symbol in der oberen rechten Ecke und wählen Sie *Installieren Add-on aus Datei*
- Suchen Sie die heruntergeladene `.xpi`-Datei und klicken Sie auf *Öffnen Sie* - Zotero wird das Plugin installieren.
- Starten Sie Zotero, um das Plugin zu aktivieren.

4. Bessere BibTeX konfigurieren:
- Nach der Installation finden Sie bessere BibTeX-Einstellungen im Zotero-Einstellungen (Windows) oder Einstellungen (Linux) Menü unter dem *Better BibTeX* Tab.
- Richten Sie Ihr Zitat-Schlüsselformat und Exporteinstellungen nach Ihrem Workflow ein; unsere Empfehlung:
     ```
     auth.lower + year + shorttitle(1,1).lower
     ```

5. Export und Nutzung:
- Um eine Bibliographie zu exportieren, wählen Sie die gewünschten Referenzen in Zotero, mit der rechten Maustaste und wählen Sie *Export Items*
- Wählen Sie *Better BibTeX* als Exportformat aus; beachten Sie, dass die *Better BibLaTeX* die gewünschte Funktionalität nicht erzeugen kann und bei der Erstellung einer `.tex`-Datei untraceable Fehlermeldungen verursachen kann.
- Optional, überprüfen Sie das *keep aktualisiert* Feld im nächsten Fenster

For the domains of water resources reasearch and hydraulic engineering, you may want to work with our hydro-informatics.com library: [https://www.zotero.org/groups/4917569/hydro-informatics/library](https://www.zotero.org/groups/4917569/hydro-informatics/library).

### Automerge mehrere Duplikate

Die Verschmelzung von Duplikaten in Zotero kann mit einem Mausklick erfolgen, aber nur mit einem Mausklick und einem Item-by-item. Dies kann viel Zeit beim Zusammenführen großer Bibliotheken nehmen. Hier ist ein Workaround zum auto-merge multiple duplicates in Zotero.

```{admonition} Make sure all duplicates have the same Item Type
:class: important

Um den folgenden Auto-Merge-Code reibungslos funktionieren zu lassen, gehen Sie über Ihre Duplikate und suchen Sie nach markierten Duplikaten, die verschiedene Artikeltypen haben. Als nächstes harmonisieren Sie die Artikeltypen von doppelten Paaren (d.h. ändern Sie die Artikelart eines der betroffenen Einträge). Dies ist ein bisschen mühsam, aber dauert nicht zu lange und viel schneller als jedes Duplikat zusätzlich mit Mausklick zu verschmelzen.
```

* Öffnen Sie die Zotero-Anwendung auf Ihrem Computer (nicht im Browser)
* Zum **Duplicate Items** Eintrag Ihrer Bibliothek
* Alle Highlights (Presse`CTRL` und `A`keys)
* Gehe zu **Tools** (Top-Menü) > **Entwickler********, kopiere den folgenden Codeblock in das **Code** Feld ein und klicke **Run***


```
var DupPane = Zotero.getZoteroPanes();

for(var i = 0; i < 999; i++) {
  try {
    await new Promise(r => setTimeout(r, 50));
    DupPane[0].mergeSelectedItems();
    Zotero_Duplicates_Pane.merge();
  } catch (e) {
    console.log(e);
  }
}
```

Der Codeblock macht maximal 999 Iterationen, die durch Erhöhung der Iterationszahl in der für Schleife des JavaScript-Codes erhöht werden können.


Diese Antwort ist inspiriert von Diskussionen im [Zotero Forum](https://forums.zotero.org/discussion/40457/merge-all-duplicates).

## Bibliographie

Bei der Arbeit mit LaTeX umfasst das bibliographische Management in der Regel eine .bib-Datei, die alle Ihre Referenzen enthält, die Sie im `.tex`Dokument unter Verwendung von `\cite{...}` (oder ähnliche) Befehlen ansagen. Um diese Zitate und Referenzen in eine richtig formatierte Bibliographie zu verwandeln, führen Sie iterativ ein Tool wie BibTeX, nachdem Sie Ihr LaTeX-Dokument erstellt haben. ** Beachten Sie, dass TexStudio diese Iterationen automatisch während des Compiling** macht, so erklären diese Beschreibungen nur, warum Sie den Compiling-Prozess mehrmals neu starten sehen können, obwohl Sie nur einmal die Taste "Compile" gedrückt haben.

BibTeX liest die `.aux`-Datei einer vorherigen Zusammenstellung des `.tex`-Dokuments, ordnet die entsprechenden Einträge in der `.bib`-Datei an und erstellt dann eine `.bbl`-Datei, die nur die genannten Referenzen enthält, die nun nach den durch eine Bibliographie-Stil-Datei definierten Stilregeln formatiert werden (z.B. eine `.bst`-Datei bei BibTeX). Diese Stildateien steuern das Aussehen und die Anordnung von Zitaten und Referenzen, einschließlich wie Autoren, Titel und Zeitschriftennamen angezeigt werden. Sobald die `.bbl`-Datei generiert wird, enthält LaTeX sie während des nächsten Zusammenstellungslaufs in das endgültige PDF-Dokument. Die `.bbl`-Datei ist somit eine voll formatierte Untermenge der `.bib`-Datenbank, um sicherzustellen, dass das PDF-Dokument nur die tatsächlich zitierten Referenzen anzeigt, nach den gewählten Formatierungsrichtlinien arrangiert und gestylt.

Um Ihre Referenzdatenbank zu verwalten und eine `.bib`-Datei zu generieren, empfehlen wir Ihnen Tools wie [Zotero](https://www.zotero.org/) (mit zusätzlichen Tipps im Abschnitt {ref}`Zotero Tips <debug-zotero>`). Unsere [LaTeX-Thesis Template](https://github.com/Ecohydraulics/latex-thesis-template) bietet mehr Anleitung für die Zusammenarbeit mit Zotero und die Verwaltung der `.bib`-Datei.
