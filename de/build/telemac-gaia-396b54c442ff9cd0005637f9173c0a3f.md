#  Gaia (Morphodynamik)

```{figure} ../../img/hydro-morphodynamics.png

Ein morphodynamisch aktiver Nebenfluss des Cache Creek in Kalifornien, USA.
```

This chapter guides through modeling {term}`Sedimenttransport <Sediment transport>` and related phenomena in rivers (morphodynamics) with Telemac2d and the Gaia module. Specifically, a simple steady 2d example demonstrates how {term}`Sedimenttransport <Sediment transport>` in the form of {term}`Geschiebe <Bedload>` and {term}`Schwebstoff <Suspended load>` can be modeled with the TELEMAC software suite.
