# Virtuelle Maschinen Debugging

## Fehlermeldung: Hardwarebeschleunigung nicht verfügbar

Diese Fehlermeldung kann durch *VirtualBox* (oder andere Hypervisoren) aufgrund einer Einstellung im BIOS des Hostsystems erhöht werden. Um den Fehler zu beheben:

* Starten Sie den Computer neu.
* Geben Sie beim Start das Boot-Menü ein: Am Anfang des Systemstarts drücken Sie in der Regel die Taste `F2` oder `DEL`. Abhängig vom Computer können andere Schlüssel gelten (z.B. `F12` - siehe den Bildschirm für Informationen über den Zugriff auf `Setup`).
* Der Bootmanager öffnet sich. Verwenden Sie die Pfeiltasten, um an die `Advanced settings` zu navigieren, angeben und an `CPU Configuration`.
* In der `CPU Configuration`, gehen Sie an `Secure Virtual Machine`. Wenn es eine `[Disabled]`-Flag gibt, klicken Sie auf den Eingabeschlüssel, um auf `[Enabled]` zu wechseln.
* Klicken Sie auf `Esc`, wenden Sie sich an `Exit` >`Save changes and exit` (oder klicken Sie einfach auf den `F10`Schlüssel). Bestätigen Sie. Das System wird jetzt neu starten.
* Zurück in *Windows* re-run *VirtualBox* und starten Sie eine VM. Die Fehlermeldung sollte nicht mehr angezeigt werden.


## Grafische Benutzeroberflächen stürzen

Die Verwendung von *OpenGL* mit virtuellen Maschinen auf *VirtualBox* befindet sich noch in einer experimentellen Phase und kann insbesondere mit *nvidia* Grafikkarten ausfallen. Um *nvidia* Treiber zu installieren, aktivieren Sie *non-free* Pakete und installieren Sie *nvidia-detect*, um einen geeigneten Treiber abzurufen:

 * Öffnen Sie `etc/apt/sources.list` und ändern Sie die `buster`repository Definition (Beispiel für Server in Deutschland):
    + Original: `deb http://ftp.de.debian.org/debian/ buster main`
    + to: `deb-src http://ftp.de.debian.org/debian/ buster main non-free`
* In *Terminal* aktualisieren Sie Repositories und installieren Sie `nvidia-detect`

```
sudo apt update
sudo apt -y install nvidia-detect
```

Dann, installieren Sie den *nvidia* Treiber (oder was auch immer der vorherige Befehl empfohlen):

```
sudo apt install nvidia-driver
```

Reboot Debian, um zu beenden:

```
systemctl reboot
```
