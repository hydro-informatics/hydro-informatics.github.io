# Open Acces und Source

Dieses Kapitel führt durch Open-Access- oder Open-Source-Softwareressourcen. Im ersten Abschnitt werden virtuelle Maschinen (VMs) und *Debian Linux* (und Spin-offs) vorgestellt.

```{admonition} The difference between Open Access and Open Source
Open-Access-Software ist unter gemeinsamen Open-Access-Lizenzen frei verfügbar. Neben der freien Verfügbarkeit baut Open-Source-Software auf öffentlich verfügbarem Quellcode auf. Somit kann Open-Source-Software von Nutzern mit frei verfügbarem Code im Internet modifiziert werden. Um die gemeinsame Nutzung von Open-Access- oder Open-Source-Software zu ermöglichen, muss der Entwickler eine Lizenz zusammen mit dem Code oder der Software bereitstellen. Lesen Sie mehr über Lizenzen auf der Plattform der [creative commons organization](https://creativecommons.org/)].
```

Linux-basierte {term}`Betriebssystem <Operating System>`s (OSs) erleichtern aufgrund der sehr hohen Stabilität und Leistung datenbezogene wissenschaftliche und technische Aufgaben erheblich. Dennoch ermöglicht die bestehende Infrastruktur vieler Institutionen die Verwendung von Linux nicht, und hier können virtuelle Maschinen helfen: Sie ermöglichen das Ausführen eines anderen (Gast-) Betriebssystems auf dem Host-Betriebssystem über ein Virtualisierungs-Framework.

Die in diesem Abschnitt vorgestellte Software ist nicht nur für Linux konzipiert und kann auch auf vielen anderen Betriebssystemen installiert werden. Genießen Sie das Lesen und Durchlaufen der Tutorials zu Geospatial Software, Git, numerischer Modellierungssoftware und anderen hilfreichen Programmen.
