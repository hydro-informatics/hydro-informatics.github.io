(gdal)=
## OSGeo und GDAL Einschließlich ogr und osr

Die [gdal](https://gdal.org/)-Bibliothek für {ref}`raster data handling <raster>` kommt zusammen mit [ogr](https://gdal.org/faq.html?highlight=ogr) für {ref}`vector data handling <vector>` und [osr](https://gdal.org/python/osgeo.osr-module.html) für Georeferenzierung]. GDAL und OGR werden von [OSGeo Project](http://www.osgeo.org/)] verwaltet und entwickelt, das Teil der Open Source Geospatial Foundation ist - den Entwicklern von {ref}`qgis-install`.

The tutorials in this eBook build on `gdal` and `ogr` (including `osr` for spatial referencing), which is why it is important to get the installation of `GDAL` right:

* **Linux**-Benutzer können die Anweisungen zur Installation von `gdal` und [flusstools](https://flusstools.readthedocs.io) mit {ref}`pip and venv <pip-env>`] befolgen.
* **Windows**-Benutzer installieren vorzugsweise `gdal` und [flusstools](https://flusstools.readthedocs.io) in einem {ref}`conda environment <conda-env>` über Anaconda].


Wählen Sie Ihre Plattform für spezifischere Installationsanweisungen:

`````{tab-set}
````{tab-item} Linux / pip

GDAL requires sudo-installation. Find more details in the {ref}`Python installation instructions <pip-env>` of this eBook.

````

````{tab-item} Windows / conda
Um `GDAL` für Python über {ref}`Anaconda Prompt <install-pckg>` zu installieren, geben Sie an:

```python
conda install -c conda-forge gdal
```
````
`````

````{admonition} Import GDAL, ogr, and osr from OSGeo
:class: important

Der direkte Import von `gdal`, `ogr` und `osr` (z. B. `import gdal`) ist seit GDAL v3 veraltet. Daher müssen `gdal`, `ogr` und `osr` von `osgeo` importiert werden:

```python
from osgeo import gdal
from osgeo import osr
from osgeo import ogr
```
````

## Geojson
Die [geojson](https://pypi.org/project/geojson/)-Bibliothek ist die direkteste Option für den Umgang mit {ref}`geojson`-Daten und ist auch bereits zusammen mit [flusstools](https://flusstools.readthedocs.io)] installiert.

`````{tab-set}
````{tab-item} Linux / pip
Um `geojson` zu installieren, öffnen Sie *Terminal * und geben Sie ein:

```python
pip install geojson
```
````

````{tab-item} Windows / conda
Um `geojson` für Python Anaconda zu installieren, öffnen Sie {ref}`Anaconda Prompt <install-pckg>` und geben Sie ein:

```python
conda install -c conda-forge geojson
```
````
`````

(descartes)=
## Descartes Labs
Even though of proprietary origin, the [`descarteslabs`](https://docs.descarteslabs.com/api.html) library (developed and maintained by [Descartes Labs](https://www.descarteslabs.com/)) comes with many open-sourced functions. Moreover, Descartes Labs hosts the showcase platform [GeoVisual Search](https://search.descarteslabs.com/) with juicy illustrations of artificial intelligence (AI) applications in geoscience. Note that `descarteslabs` is not installed along with [flusstools](https://flusstools.readthedocs.io).

`````{tab-set}
````{tab-item} Linux / pip
To install `descarteslabs`, open Terminal and type:

```python
pip install descarteslabs
```
````

````{tab-item} Windows / conda
Um `descarteslabs` für Python zu installieren, öffnen Sie {ref}`Anaconda Prompt <install-pckg>` und geben Sie ein:

```python
conda install -c conda-forge descartes
```

Wenn die Installation fehlschlägt, versuchen Sie Folgendes:

```python
conda install shapely
pip install descarteslabs
```
````
`````

## Python Imaging Library (PIL) / Kissen
Processing images with Python is enabled with the *Python Imaging Library* (*PIL*). *PIL* supports many image file formats and has efficient graphics processing capabilities. The `pillow` library is a user-friendly *PIL* fork and provides `Image*` modules (e.g., `Image`, `ImageDraw`, `ImageMath`, and many more). If [flusstools](https://flusstools.readthedocs.io) is installed, no further action is required for working with the *PIL*/*pillow*-related contents of this eBook.

Note that the `conda base` environment includes `PIL` (test with `import PIL`), which needs to be uninstalled before installing `pillow`. For installing *PIL*/*pillow*, refer to [https://pillow.readthedocs.io](https://pillow.readthedocs.io/en/stable/installation.html).

## Andere Verpackungen

Neben den oben genannten Paketen gibt es weitere nützliche Bibliotheken für Geodatenanalysen mit Python (**`Packages in bold red font`** werden zusammen mit [flusstools](https://flusstools.readthedocs.io)] installiert):

 * [**`alphashape`**](https://pypi.org/project/alphashape/)] erzeugt begrenzende Polygone, die eine Reihe von Punkten enthalten.
 * [django](https://docs.djangoproject.com/en/3.0/ref/contrib/gis/)] als geografischer Webframe und für Datenbankverbindungen.
 * [**`geopandas`**](https://geopandas.org/)] ermöglicht die Anwendung von {ref}`pandas`-Datenrahmenoperationen auf Geodatensätze.
 * [NetworkX](https://networkx.github.io/documentation/stable/index.html) für Netzwerkanalysen wie das Finden eines kostengünstigsten / kürzesten Pfades zwischen zwei Punkten].
 * [owslib](http://geopython.github.io/OWSLib/) zur Verbindung mit den Webdiensten des *Open Geospatial Consortium* (OGC).
 * [postgresql](https://www.postgresqltutorial.com/postgresql-python/) für SQL-Datenbankverbindungen].
 * [**`rasterio`**](https://rasterio.readthedocs.io/en/latest/)] für die Verarbeitung von Rasterdaten als {ref}`numpy`-Arrays.
 * [**`rasterstats`**](https://pythonhosted.org/rasterstats/) erzeugt zonale Statistiken von Rastern und kann mit {ref}`geojson`-Dateien interagieren.]
 * [**`sckit-image`**](https://scikit-image.org/)] für maschinelles Lernen, das auf georeferenzierte Bilder angewendet wird.
