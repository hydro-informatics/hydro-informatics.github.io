# Git und Markdown

```{admonition} Goals
Benutzen Sie *git* und lernen Sie die Beschriftungsdokumente kennen.
```

```{admonition} Requirements
:class: attention
Verstehen Sie [git](../get-started/git) und [markdown](../documentation/how-to-document).
```

Bereiten Sie sich durch Klonen des Übungs-Repository:

```
git clone https://github.com/Ecohydraulics/Exercise-git.git
```

*** Beschreiben Sie Ihren Lieblingsdamm, Fisch oder Fluss in einer Markdown-Datei namens `README.md`.

```{admonition} Features to implement in the `README.md` file
:class: attention


* Link zum Bild online
* Schreiben Sie mindestens 150 Wörter über das Objekt
* Tabelle zusammenfassende Schlüsselparameter
* Liste mindestens zwei ähnliche Strukturen / Flüsse / Fische
* Implementieren Sie klickbare Links zu Quellen (Website, pdf Downloads) verwendet
