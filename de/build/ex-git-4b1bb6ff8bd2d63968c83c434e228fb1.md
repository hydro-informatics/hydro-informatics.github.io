# Git und Markdown

```{admonition} Goals
Verwenden Sie *git* und machen Sie sich mit dem Schreiben von Markdown-Dokumenten vertraut.
```

```{admonition} Requirements
:class: attention
Verstehen Sie [git](../get-started/git) und [markdown](../documentation/how-to-document)].
```

Machen Sie sich bereit, indem Sie das Übungsrepository klonen:

```
git clone https://github.com/Ecohydraulics/Exercise-git.git
```

***Aktivität:*** Beschreiben Sie Ihren Lieblingsdamm, Fisch oder Fluss in einer Markdown-Datei namens `README.md`.

```{admonition} Features to implement in the `README.md` file
:class: attention


* Link zum Bild online
* Schreiben Sie mindestens 150 Wörter über das Objekt
* Tabelle Zusammenfassung der Schlüsselparameter
* Liste mindestens zwei ähnliche Strukturen / Flüsse / Fische
* Implementieren Sie klickfähige Links zu verwendeten Quellen (Website, PDF-Downloads)
