# Virtuelle Maschinen und Linux

Ihr Computer ist einer Ihrer wichtigsten Bildungsbegleiter. So möchten Sie die Gesundheit Ihres Computers schützen und Probleme vermeiden, die durch redundante oder sogar bösartige Software verursacht werden. Aus diesem Grund wird empfohlen, alle auf dieser Website verwendeten Software auf einer sogenannten Virtual Machine (VM) zu installieren. Diese Seite erklärt, was VMs sind, welche Vorteile sie genau haben und wie Sie installieren können [Debian Linux](https://www.debian.org/), eines der stabilsten und sichersten Betriebssysteme. Es spielt keine Rolle, ob Sie Apples *mac OS* oder Microsofts *Windows* verwenden, oder wenn Sie bereits Linux verwenden: Die VM wird am Ende gleich aussehen.


## Über uns

### Was ist eine virtuelle Maschine (VM)?

Eine virtuelle Maschine (VM) stellt ein virtuelles Betriebssystem (OS) dar, das auf einem Hostsystem läuft, das direkt auf einem physischen Computer läuft. Die physikalischen Rechner (Hardware) Ressourcen des Hostsystems werden über sogenannte Hypervisors zugewiesen. Aus diesem Grund wird die virtuelle Maschine als *Gastmaschine* und der Hypervisor als *Host-Maschine* bezeichnet. So ist eine *guest-Maschine* eine isolierte, virtualisierte Umgebung, die unabhängig vom Host-Betriebssystem verläuft.

### Warum einen VM verwenden?

Freie Ressourcen auf einem Computer stellen aus ökonomischer Sicht einen toten Speicherplatz dar, der Kosten verursacht, ohne Einkommen zu generieren. Deshalb erstellen Systemadministratoren oft mehrere virtuelle Server, um physische Ressourcen besser zuzuordnen und Energie zu sparen. Ein VM ist auch für intelligente Endbenutzer wie Forscher und Ingenieure nützlich. Hier sind einige Vorteile eines VM:

* Anwendungen und Dienste mehrerer VMs stören sich nicht gegenseitig.
* Unabhängigkeit des Gastsystems vom Betriebssystem des Hostsystems und der physischen Hardware.
* VMs können durch einfaches Kopieren auf andere Systeme bewegt oder geklont werden.
* Hardwareressourcen können über den Host-Hypervisor dynamisch zugewiesen werden.
* Bessere und effizientere Nutzung bestehender Hardwareressourcen.
* Kurze Einsatzzeiten für Systeme und Anwendungen, die auf einem VM laufen.
* VMs bieten aufgrund ihrer Unabhängigkeit von physischen Ressourcen hohe Verfügbarkeit und Flexibilität.


Im Rahmen der Hydroinformatik für das Wasserressourcenmanagement kann ein VM dazu dienen, verschiedene *Python*-Skripte mit unterschiedlichen Abhängigkeiten auszuführen oder vor allem eine saubere und effiziente Umgebung für die Ausführung von numerischen Modellen wie [open TELEMAC-MASCARET](http://www.opentelemac.org/).

Dieses Tutorial bietet Beratung zu {ref}`creating a new VM <vm-create>`, {ref}`re-using an existing VM <hyfo-vm>` und {ref}`working with Debian Linux on a VM <debian>`.

## Erstellen eines VM mit VirtualBox

** Geschätzte Dauer: 5-8 Minuten.**

In Ihrem Host-System (z.B. *Windows 11*), klicken Sie auf *Start*, geben Sie *Oracle VM VirtualBox* und klicken Sie auf Enter. Im geöffneten *VirtualBox* Managerfenster:

* Klicken Sie auf den blauen *Neu*-Button, um den VM-Erstellungsassistenten zu öffnen und einzugeben:
  + *Name:* Debian Linux <br>* Hinweis: Der Assistent sollte automatisch den * Type * und *Version *fields erkennen.*
  + *Machine Folder:* `C:\Users\USERNAME\VirtualBox VMs`
  + *Typ:* Linux
  + *Version:* Debian (64-bit) <br>> Klicken Sie auf die Schaltfläche *Weiter*
  + Speichergröße zuordnen: Je mehr Speicher dem VM zugeordnet wird, desto schneller wird der VM (und zum Beispiel TELEMAC-MASCARET) sein, desto langsamer wird das Hostsystem (*Windows 11*) sein. Daumenregel: Bleiben Sie im grünen Bereich der Bar (z.B. 8192 MB oder mehr)
<br>> Klicken Sie auf die Schaltfläche *Weiter*
  + Wählen Sie *Jetzt eine virtuelle Festplatte erstellen* und klicken Sie auf die *Kreate* Taste.
  + Wählen Sie *VDI* (native to *VirtualBox*) und klicken Sie auf *Next*.
  + Vorzugsweise wählen Sie *Dynamisch zugeordnet*, um mit einer kleinen virtuellen Festplattengröße zu beginnen, die eine maximale Größe im nächsten Schritt definieren kann. Klicken Sie auf die Schaltfläche *Weiter*.
  + Hinterlassen Sie den Standard-Datenträgernamen wie es ist und stellen Sie eine maximale Größe für die virtuelle Festplatte (empfohlen: min. 32 GB) zu. Klicken Sie auf die *Create* Taste.
* Toll - die Grundlagen sind jetzt alle gesetzt und wir sind wieder im *VirtualBox* Hauptfenster, wo ein *Debian Linux* VM jetzt auf der linken Seite des Fensters sichtbar sein sollte.
* Mit dem *Debian Linux* VM hervorgehoben (d.h. klicken Sie einfach darauf), klicken Sie auf die gelbe *Einstellungen* Radtaste, die das *Einstellungen* Fenster öffnet:
  + In der Registerkarte *System/Motherboard* überprüfen Sie die Speicherzuordnung und überprüfen Sie das *Enable EFI (nur spezielle Betriebssysteme)* Feld (aktivieren).
  + Wählen Sie in der Registerkarte *System/Prozessor* die Anzahl der Prozessoren aus, die der VM verwendet. Um das Host-System zu verlangsamen (*Windows 11*), bleiben Sie im grünen Bereich der CPU-Bar. Für die parallele Verarbeitung mit TELEMAC-MASCARET stellen mindestens 4 CPUs zur Verfügung.
  + In der Registerkarte *Display*, überprüfen Sie die *Enable 3D Acceleration* Box.
  + In der Registerkarte *Speicher* finden Sie den *Controller: IDE*, wo sich unten ein *Empty* Laufwerkssymbol befindet.
    - Klicken Sie auf das *Empty*-Disk-Symbol und finden Sie den *Attributes*-Rahmen auf der rechten Seite des Fensters, wo ein kleines blaues Laufwerk-Symbol sichtbar sein sollte.
    - Klicken Sie auf das kleine blaue Festplattensymbol, um * Wählen Sie eine Festplattendatei ...* Wählen Sie den Debian Linux-Netzwerk-Installer (z.B. *debian-13.x.x-amd64-netinst.iso*), den Sie zuvor heruntergeladen haben.
  + Klicken Sie auf *OK*.

## Installieren Sie Debian Linux

** Geschätzte Dauer: 30 Minuten.**

Um Debian Linux auf das VM zu installieren, starten Sie im *VirtualBox*-Manager-Fenster das zuvor erstellte *Debian Linux VM* (klicken Sie auf den *Debian Linux* VM und dann auf den grünen *Start* Pfeil). Das *VirtualBox VM*-Fenster wird die *.iso*-Datei verwenden (bestätigen Sie die ausgewählte), und starten Sie navigieren durch die Installation:

* Wählen Sie im Fenster *VirtualBox VM* die Option *Graphical install* aus.
* Navigieren Sie durch die Sprachoptionen (empfohlen: Englisch - Englisch (US)).
* Optional einen Hostnamen (z.B. debian-vm) und einen Domainnamen (z.B. debian-net) definieren.
* Erstellen Sie einen Root-Benutzernamen und ein Passwort (schreiben Sie die Anmeldeinformationen irgendwo) sowie einen Benutzernamen (keine Root-Rechte) und ein Passwort.
* Stellen Sie die Uhr ein.
* Disk-Partitionierung: Wählen Sie die *Guided - verwenden Sie die gesamte Festplatte * Option. Klicken Sie auf *Weiter* (2 mal).
* Wählen Sie die *Alle Dateien in einer Partition (empfohlen für neue Benutzer)* Option. Klicken Sie auf *Weiter*.
* Stellen Sie sicher, dass * Partitionierung erstellen und Änderungen an der Festplatte * ausgewählt werden und klicken Sie auf *Weiter*.
* Wählen Sie *Ja* im nächsten Schritt (*Write die Änderungen an Festplatten?*). <br>... packen Sie Ihr Lieblingsgetränk und warten Sie, während die Installation fortfährt...
* Wählen Sie *No*, um die Frage zu beantworten *Scannen Sie eine andere CD oder DVD?* und klicken Sie auf *Weiter*.
* Wählen Sie den geografisch nächstgelegenen Spiegel, um auf Debian-Archive (Software-Repositories und Updates) zuzugreifen und klicken Sie auf *Weiter* (2 mal).
* Überspringen Sie die Proxy-Informationsfrage (nur klicken Sie auf *Weiter*).
* Wählen Sie optional *No* aus, um die Frage zu beantworten *Erwarten Sie in der Umfrage zur Paketnutzung?* und klicken Sie auf *Weiter*.
* Software zu installieren: Wählen Sie *GNOME* (Standard Debian-Desktop) und halten Sie die anderen Standardeinstellungen (Debian-Desktop, Druckserver und Standard-Systemprogramme). Seit Debian 12 ermöglicht der Installer standardmäßig auch die **non-free-firmware***-Komponente, die Debian 13 (Trixie) als erstklassiges Repository-Komponente für Hardwaretreiber behandelt.
<br>... genießen Sie weiterhin Ihr Lieblingsgetränk und warten, während die Installation fortfährt...
* Klicken Sie auf *Weiter*, um die Installation zu beenden und die VM neu zu starten (oder abzuschalten).

Sobald der VM geschlossen ist, öffnen Sie die VM *Settings* (aus *VirtualBox Manager* Fenster) und gehen Sie auf die *Storage* Registerkarte. Überprüfen Sie, dass im Feld *Controller: IDE* wieder ein *Empty*-Disk-Symbol vorhanden ist.


## Wiederverwendung (Export/Transfer oder Kopieren) eines VM auf einem anderen Host

Sobald Sie ein VM auf einer virtuellen Festplatte erstellt haben (die `*.vdi`-Datei), können Sie es immer auf ein anderes *host*-System mit seinem Ökosystem übertragen. Zum Kopieren (oder Transportieren) der VM:

* Auf dem ursprünglichen Host:
  * Schließen Sie die VM ab, die Sie wiederverwenden möchten.
  * In VirtualBox gehen Sie auf **Datei*****Export Appliance...**.
  * Folgen Sie den Anweisungen, um die VM in eine `*.ova`-Datei zu exportieren (der **export-Prozess kann 10-15 Minuten dauern*).
* Auf dem neuen Host:
  * Stellen Sie sicher, dass VirtualBox installiert ist.
  * Kopieren Sie die exportierte `*.ova`-Datei in das neue Hostsystem.
  * Öffnen Sie VirtualBox und gehen Sie zu **Datei****
  * Navigieren Sie in das Verzeichnis, in dem Sie die `*.ova`-Datei kopiert haben.
  * Klicken Sie auf **Weiter**.
  * Überprüfen Sie die ** Geräteeinstellungen* und klicken Sie auf **Import***.

Nun sollte die virtuelle Maschine in der Liste der virtuellen Maschinen in VirtualBox sichtbar sein.

(hyfo-vm)=
## Importieren eines vorhandenen VM in Oracle VM VirtualBox

Anstatt einen neuen VM von Grund auf zu erstellen, können Sie einen vorhandenen VM in Oracle VM VirtualBox importieren. Dies ist nützlich, wenn ein VM bereits mit der erforderlichen Betriebssystem-, Software-, Einstellungen- und Benutzerumgebung konfiguriert wurde.

Vorhandene VMs werden häufig in einem der folgenden Formate bereitgestellt:

* eine Gerätedatei, typischerweise `.ova` oder `.ovf`
* ein virtuelles Festplattenbild wie `.vdi`, `.vmdk` oder `.vhd`

Das Einfuhrverfahren hängt vom Dateityp ab.

### Importieren einer VM-Appliance

Stellen Sie sicher, dass Oracle VM VirtualBox installiert ist, wie unter {ref}`the VM requirements <vm-requirements>` beschrieben. Dann öffnen Sie VirtualBox und:

* Gehen Sie zu **Datei*****
* Wählen Sie die Datei `.ova` oder `.ovf`.
* Klicken Sie auf **Weiter**.
* Überprüfen Sie die Geräteeinstellungen, einschließlich:
  * VM-Name
  * Basisordner
  * CPU-Zuweisung
  * RAM-Zuweisung
  * Netzwerkadaptereinstellungen
  * Speicherort der virtuellen Festplatte
* Stellen Sie die Einstellungen bei Bedarf ein.
* Klicken Sie auf **Finish** oder **Import***.

Nach dem Import sollte die VM in der Liste der verfügbaren VMs in VirtualBox erscheinen.

### Registrieren Sie eine bestehende virtuelle Festplatte

Wenn der VM als virtuelles Festplattenbild anstatt als Gerät bereitgestellt wird, erstellen Sie ein neues VM und befestigen Sie die vorhandene Festplatte:

* Klicken Sie auf **Neu** in VirtualBox.
* Geben Sie einen VM-Namen ein.
* Wählen Sie den entsprechenden OS-Typ und -Version aus.
* RAM und CPU-Ressourcen zuordnen.
* Wählen Sie **Benutzen Sie eine bestehende virtuelle Festplattendatei**.
* Wählen Sie die Datei `.vdi`, `.vmdk` oder `.vhd`.
* Beenden Sie das VM-Setup.

Bevor Sie die VM starten, überprüfen Sie die VM-Einstellungen und stellen Sie sie bei Bedarf ein.

### Starten und Konfigurieren des importierten VM

Nach dem Import oder Registrierung des VM starten Sie es aus dem VirtualBox Hauptfenster. Überprüfen Sie beim ersten Start die folgenden Artikel:

* **Keyboard Layout**: Stellen Sie sicher, dass das Gäste-Betriebssystem das erwartete Tastaturlayout verwendet.
* **Berechtigungen*: Verwenden Sie die mit der VM-Dokumentation bereitgestellten Anmeldeinformationen.
* ** Netzzugang**: Prüfen Sie, ob das VM NAT verwendet, überbrückte Vernetzung oder einen anderen Netzwerkmodus.
* **Einstellungen anzeigen**: Stellen Sie die Bildschirmauflösung und die Skalierung bei Bedarf ein.
* **Guest Additions*: Installieren oder aktualisieren Sie VirtualBox Guest Additions, wenn geteilte Zwischenablage, dynamisches Resizing oder Ordner-Sharing nicht funktionieren.
* **Systemaktualisierung*: Wenn das Guest OS Paket-Updates unterstützt, aktualisieren Sie es, bevor Sie zusätzliche Software installieren.
* **Ausgewählte Ordner*: Um Dateien zwischen Host- und Gastsystemen auszutauschen, konfigurieren Sie freigegebene Ordner wie unter {ref}`folder sharing <vm-share>` beschrieben.

Für Linux-Gäste können Systemupdates in der Regel vom grafischen Update Manager oder vom Terminal gestartet werden. Verwenden Sie für Debian- oder Ubuntu-basierte Systeme:

```bash
sudo apt update
sudo apt full-upgrade
sudo apt autoremove
```

### Empfohlene VM-Einstellungen

Bevor Sie den VM für größere Berechnungen oder Software-Installationen verwenden, überprüfen Sie die folgenden Einstellungen:

* **RAM**: Geben Sie genügend Speicher für die Gäste OS und Anwendungen, aber lassen Sie genügend RAM für das Host-System.
* **CPU**: Zuordnung mehrerer CPU-Kerne nur, wenn das Host-System genügend Ressourcen hat.
* **Storage**: Stellen Sie sicher, dass die virtuelle Festplatte genügend Freiraum hat.
* **Netzwerk**: Verwenden Sie NAT für einfachen Internetzugang oder überbrückte Vernetzung, wenn die VM im lokalen Netzwerk sichtbar sein muss.
* **Snapshots*: Erstellen Sie einen Snapshot vor großen Updates oder Konfigurationsänderungen.

Mit einem Snapshot können Sie in einen vorherigen VM-Zustand zurückkehren, wenn ein Update-, Installations- oder Konfigurationsschritt ausfällt.

## Setup Linux

** Geschätzte Dauer: 15 Minuten.**

Starten Sie das *Debian Linux* VM aus dem *VirtualBox* Manager-Fenster. Sobald Debian Linux gestartet ist, loggen Sie sich mit Ihren Benutzerinformationen ein.

To enable the full functionality of the system, open the Linux Terminal (`CTRL` + `Alt` + `T` or go to *Activities* > *Files* (filing cabinet symbol), right-click in any folder and select *Open in Terminal*). In *Terminal* type:

```
su
```

Geben Sie das oben erstellte Passwort für den Root-Benutzernamen ein (siehe Installationsabschnitt).

```{note}
Root-Zugriff (z.B. zur Installation von Software) wird auf vielen Linux-Distributionen mit dem `sudo`-Befehl vor dem Befehl zur Ausführung erteilt. In Debian Linux kann sich `sudo` auf das falsche Konto beziehen und nicht wie gewünscht arbeiten. Als Workaround-Typ `su` in *Terminal*. Lesen Sie mehr später in diesem Abschnitt.
```

Installieren Sie alle für den Aufbau von Kernel-Modulen erforderlichen Pakete:

```
apt update
apt install build-essential dkms linux-headers-$(uname -r)
```

Finden Sie das *Devices* Dropdown-Menü des *VirtualBox VM*-Fensters (nicht in Debian Linux selbst) und wählen Sie *Insert Guest Additions CD-Bild...* (je nach Version von *VirtualBox* kann dieses Menü oben oder unten im Fenster sein).

```{admonition} Where is the **Devices** entry?
:class: tip
Das *VirtualBox VM* Fenster zeigt das Menü nicht mit dem *Devices* Eintrag irgendwo?

* Dies kann passieren, wenn der *View* auf *Scaled-Modus* eingestellt wurde.
* Um den Ansichtsmodus zu wechseln und die Menüleiste sichtbar zu machen, drücken Sie die Taste RECHT`CTRL` (`Host`) + die `C` auf Ihrer Tastatur, während Sie in der Host-Systemansicht sind.
```

```{admonition} If the error **The guest system has no CR-ROM ...** occurs...
:class: warning
Um die Fehlermeldung `The guest system has no CR-ROM ...` zu beheben, schalten Sie die VM herunter. Im *VirtualBox* Manager-Fenster klicken Sie mit der rechten Maustaste auf den *Debian Linux* VM > *Storage* Tab > Fügen Sie neue Optical Drive zu *Controller: IDE*. Starten Sie die *Debian Linux* VM.
```

Zurück in der Debian Linux *Terminal*, mounten Sie die *Guest Additions* *iso* Datei, indem Sie in *Terminal* eingeben:

```
sudo mkdir -p /mnt/cdrom
sudo mount /dev/cdrom /mnt/cdrom
```

Navigieren Sie in das montierte Verzeichnis und führen Sie die *VBoxLinuxAdditions.run*-Datei mit dem *--nox11*-Flag aus, um ein Xterm-Fenster zu vermeiden.

```
cd /mnt/cdrom
sudo sh ./VBoxLinuxAdditions.run --nox11
```

Die Kernel-Module werden jetzt installiert und *Terminal* sollte eine Nachricht anfordern, die Sie zum Neustart des Systems einlädt. Tun Sie dies durch Tippen:

```
shutdown -r now
```

Nach dem Neustart stellen Sie sicher, dass die Installation erfolgreich war. In *Terminal* Typ:

```
lsmod | grep vboxguest
```

Die Installation war erfolgreich, wenn die Antwort von *Terminal* so ist wie `vboxguest   358395 2 vboxsf`. Lesen Sie mehr über *Guest Additions* auf der [*VirtualBox* Entwickler-Website](https://www.virtualbox.org/manual/ch04.html).

Um die visuelle Erfahrung zu verbessern, machen Sie Folgendes:
* Klicken Sie in der oberen linken Ecke des Debian Linux Desktop auf *Aktivitäten* und geben Sie *displays* im Suchfeld ein.
* Öffnen Sie die *Displays*-Einstellungen, um eine komfortable Displayauflösung auszuwählen.
  * Wenn Sie eine zu hohe Auflösung wählen, wird das *VirtualBox VM* Fenster nach 15-30 Sekunden schwarz und wieder auf die ursprüngliche Auflösung springen.
  * Denken Sie auch an *Night Light*, um Ihre Augensicht zu erhalten.
* *Anwenden* die Änderungen und schließen Sie die *Displays*-Einstellungen.

## Benutzerrechte
Bei der späteren Installation von Software ist es empfehlenswert, es für Ihr Benutzerkonto zu installieren und nicht für `root`. Solche systemrelevanten Aktionen erfordern *superuser* (`su`) Rechte. Ihr Standard-Benutzername ist jedoch nicht auf der sogenannten *sudoers*-Liste, die im Wesentlichen eine Datei ist, in der alle Benutzerkonten aufgelistet sind, die berechtigt sind, `sudo` vor jedem Befehl zu verwenden. Fügen Sie Ihr Benutzerkonto in die *su-doers*-Liste ein, indem Sie *Terminal* öffnen und tippen:

```
su
    password: ...
sudo usermod -aG sudo YOUR-USER-NAME
```

Öffnen Sie einen neuen *Terminal*-Tab (`Shift` +`CTRL` + `T`), der in Ihrem Standard-Benutzerraum mit Standard-Benutzerrechten geöffnet werden soll. Überprüfen Sie, ob Ihr Konto auf der *sudoers*-Liste steht, indem Sie eingeben:

```
sudo -v
```

Wenn visuell nichts passiert, sind Sie gut zu gehen. Ansonsten, wenn Sie eine Nachricht wie `Sorry, user [username] may not run sudo on [hostname].` erhalten, überprüfen Sie, ob Sie den obigen Befehl korrekt eingegeben haben und *YOUR-USER-NAME* (mit richtigen Fällen).

`````{tab-set}
   * Um *factory zurücksetzen* die Proton-Umgebung eines Spiels, schließen Sie Steam, dann löschen Sie seinen Ordner unter `compatdata/<APPID>/`. Sie verlieren per-game Windows-Registrierung und wineprefix-Daten (behandeln Sie es wie eine neue Windows-Installation für diesen Titel).
   * Um das Präfix schnell zu durchsuchen: klicken Sie mit der rechten Maustaste auf das Spiel > Eigenschaften > Installierte Dateien > *Browse* und navigieren nach oben in `compatdata`.

**Quick Fehlersuche Playbook:**

1. Spiel nicht starten nach einem Update:
   * Schalten Sie Proton-Version.
   * Überprüfen Sie die Spieldateien.
   * Löschen Sie das `compatdata/<APPID>` prefix und relaunch.

2. Schwarzer Bildschirm mit Audio:
   * Alt+Enter, um Vollbild zu wechseln.
   * Fügen Sie `PROTON_LOG=1` hinzu und prüfen Sie das Protokoll für fehlende 32-Bit GL/Vulkan libs.
   * Proton (oder Proton-GE).

3. Verrückter:
   * Steam-Einstellungen > Controller > aktivieren Steam Input für Ihr Gerät.
   * Per-Game > Controller > Wählen Sie ein Community-Layout oder *Gamepad mit Maus Trackpad* für KB/M-nur Titel.

````{tab-item} PlayOnLinux
:name: play-on-linux
Die derzeit vielleicht besten verfügbaren Rahmenbedingungen sind unter anderem [PlayOnLinux](https://www.playonlinux.com), die wie folgt installiert werden können:

sudo apt install winbind playonlinux winetricks -y

Beachten Sie, dass `winbind` dazu verpflichtet ist, Windows-Anmeldeinformationen für lizenzierte Software wie MS Office korrekt zu übermitteln.

Nach der Installation gehen Sie zum System **Menu** > ** Anwendungen** > Suche nach *PlayOnLinux*. Vor der Fortsetzung, eine Weinversion zu verwenden, indem Sie auf **Tools*** **Manage Wine Versions**. Die meisten Anwendungen laufen jetzt auf 64-Bit-Architekturen, so dass das Hinzufügen der neuesten amd64 Wine Version eine gute Wahl sein könnte. Nach der Installation einer Wein-Version, klicken Sie auf die **Konfigurieren** Taste im Hauptfenster, um eine Wein-Konfiguration zu verwenden und klicken Sie auf **Neu*, um eine Umgebung zu installieren (z.B. **HYINFO-ENVIRONMENT***. Folgen Sie den Installationsanweisungen.

Die Schaltfläche **+Install** öffnet ein Pop-up-Fenster mit einem Suchfeld, um nach Windows-Anwendungen zu suchen, die direkt installiert werden können. Zusätzlich, auf der Unterseite des Pop-up-Fensters, die **Installieren eine nicht-listete Programm* Option ermöglicht, andere Windows-Installateure, die nicht aufgeführt sind zu installieren. Während der ersten Installation einer Windows-Anwendung zeigt PlayOnLinux ein paar ** Nachrichten mit sehr wichtigen Informationen - nehmen Sie die Zeit, sie zu lesen*.

Um eine bestimmte **.exe** oder **.msi*** zu installieren, die Sie heruntergeladen haben, wie **BlueKenue**, klicken Sie im Hauptfenster auf die **Configure**-Schaltfläche und markieren Sie Ihre oben erstellte Umgebung. Gehen Sie auf die Registerkarte **Sonstiges** und klicken Sie auf **Run eine .exe Datei in diesem virtuellen Laufwerk**. Folgen Sie dem Installationsprozess. Um eine solche manuell installierte Software auszuführen, klicken Sie erneut auf **Configure*** > ** Verschiedenes** > ** Datei .exe in diesem virtuellen Laufwerk** ausführen und navigieren, wo das Programm gerade installiert wurde. Wenn keine direkte Verknüpfung verfügbar ist, kann das Finden der Software ein bisschen verwirrend sein, aber, keine Sorge, hier ist, wie Sie es finden:

Im Pop-up-Fenster (nach *Run a .exe file ...*) gehen Sie zu Ihrem Linux-Benutzer-Home-Ordner (z.B. `/home/hydro-informatics/`), dann aktivieren Sie die Anzeige von versteckten Dateien (press `CTRL` + `H` auf Ihrer Tastatur), die den versteckten Ordner `/home/hydro-informatics/.PlayOnLinux/` sichtbar machen. Doppelklicken Sie auf diesen versteckten Ordner, dann auf **wineprefix*** > **YOUR-ENVIRONMENT-NAME*** (z.B. **HYINFO-ENVIRONMENT**) > **drive c* und das installierte Programm entweder im **Programmdateien** oder **Programmdateien (x86)**-Verzeichnis.
Zum Beispiel, um eine 64-Bit-Installation von BlueKenue zu öffnen, navigieren Sie an `/home/hydro-informatics/.PlayOnLinux/wineprefix/HYINFO-ENVIRONMENT/drive_c/Program Files/CHC/BlueKenue64` und doppelklicken Sie auf **BlueKenue64.exe** (ersetzen Sie `hydro-informatics` und `HYINFO-ENVIRONMENT` mit Ihren lokalen Verzeichnisnamen). Das Programm sollte jetzt öffnen.

````{tab-item} Wine (Direct Installation)
Die oben beschriebene Installation von Debian Linux erstellt einen 64-Bit-VM und ermöglicht die Programmkompatibilität mit 32-Bit-Architekturen, fügt 32-Bit-Architekturen durch *Terminal* hinzu:

```
sudo dpkg --add-architecture i386 && sudo apt update
```

Dann installieren Sie *Wine* mit:

```
sudo apt install wine wine32 wine64 libwine libwine:i386 fonts-wine
```


Nach der Installation von *Wine* überprüfen oder konfigurieren Sie Ordnerlinks und Kompatibilitätsumgebungen durch Eingabe von `wine winecfg`, die das *Wine Konfiguration* Fenster öffnet, wo:

* Ordner-Links werden in der Registerkarte *Desktop Integration* definiert.
* Die Registerkarte *Applications* ermöglicht es, die *Windows*-Kompatibilitätsschicht zu definieren (z.B. *Windows 10*) und Anwendungen einzustellen.

Um eine *Windows*-Anwendung zu installieren:

1. Laden Sie den Installer herunter (z.B. eine *exe* oder *msi*-Datei).
1. Öffnen Sie *Terminal* und geben Sie `wine control` > A *Windows*-ähnliches Fenster an ([lesen Sie mehr](https://wiki.winehq.org/Control)).
1. Klicken Sie in diesem Fenster auf die Schaltfläche *Add/Remove...*, die ein weiteres Fenster öffnet (*Add/Remove Programs*).
1. Klicken Sie auf die Schaltfläche *Installieren...* und wählen Sie den heruntergeladenen *exe* oder *msi* Installer.
   * Folgen Sie den Installationsanweisungen (Standard *Windows* Verfahren).
   * Beachten Sie, dass Sie einen *Desktop Icon* hinzufügen oder das Installationsverzeichnis (z.B. `"C:\\Program Files (x86)\\CHC\\BlueKenue\\"`) beachten.
   * Im Hintergrund. *Terminal* kann die Nachricht anfordern`err:mscoree:LoadLibraryShim error reading registry key for installroot` - Sie können solche Nachrichten ignorieren ([mehr](https://forum.winehq.org/viewtopic.php?t=14618)].

```{admonition} Never run wine as root (sudo).
:class: error, dropdown
Warum? Es ist einfach nicht sicher. Also, wenn Sie ohnehin Wein als Wurzel geführt haben, rollen Sie mit `cd $HOME` und tippen Sie auf `sudo chown -R $USER:$USER .wine`
Weitere Informationen finden Sie in der [wine docs](https://wiki.winehq.org/FAQ#Should_I_run_Wine_as_root.3F).
```

**Eine *Windows*-Anwendung* durch Eingabe von `wine explorer` in *Terminal*. *Das *Windows*-Dateisystem wird in einem *Windows*-ähnlichen Fenster angezeigt. Zu Beginn und Anwendung:

* Wenn während der Installation ein *Desktop Icon* erstellt wurde, gehen Sie auf *Desktop* und doppelklicken Sie auf die Anwendung (z.B. *BlueKenue*)
* Andernfalls identifizieren Sie den Installationspfad und die ausführbare Anwendung.
   * 32-Bit-Programme werden typischerweise in `"C:\\Program Files (x86)\\` (z.B. `"C:\\Program Files (x86)\\CHC\\BlueKenue\\BlueKenue.exe"`) installiert.

* Mit dem Installationspfad kann jede *Windows*-Anwendung über *Terminal* gestartet werden mit:
   * `wine "C:\\path\\to\\the.exe"` (verwenden Sie `\\`, um Unterverzeichnisse zu trennen).
   * For example, `wine "C:\\Program Files (x86)\\CHC\\BlueKenue\\BlueKenue.exe"` typically starts *Blue Kenue<sup>TM</sup>*.
`````
