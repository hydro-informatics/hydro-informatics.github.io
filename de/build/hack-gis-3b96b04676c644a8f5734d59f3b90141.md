# GIS, Koordinatenreferenzsystem und Projektionen

## Finden Sie eine EPSG / Koordinatenreferenzsystem / Projektion

Sie haben Koordinaten eines Punktes, aber Sie wissen nicht, welches geospatiale Referenzsystem es hat?

Werfen Sie einen Blick auf [projfinder.com](http://projfinder.com/):]

* Geben Sie Ihre Koordinaten oben auf der Seite ein
* Zoom auf der Karte auf den ungefähren Ort, an dem sich dein Punkt befinden soll
* Klicken Sie auf **Find My Projection**

Vielen Dank an die Autoren von projfinder.com!
