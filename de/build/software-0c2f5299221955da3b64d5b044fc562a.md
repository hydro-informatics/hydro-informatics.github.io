# Open Acces & Source

Dieses Kapitel führt durch Open Access oder Open Source Software Ressourcen. Im ersten Abschnitt werden virtuelle Maschinen (VMs) und *Debian Linux* (und Spin-offs) vorgestellt.

```{admonition} The difference between Open Access and Open Source
Open Access Software ist unter den üblichen Open Access Lizenzen frei verfügbar. Neben frei verfügbarer Open Source Software baut auf öffentlich verfügbarem Quellcode auf. So kann Open Source Software von Benutzern mit frei verfügbarem Code im Internet geändert werden. Um Open Access oder Open Source Software zu teilen, muss der Entwickler eine Lizenz zusammen mit dem Code oder der Software bereitstellen. Lesen Sie mehr über Lizenzen auf der Plattform der [creative commons organisation](https://creativecommons.org/).
```

Linux-basierte {term}`Operating System`s (OSs) erleichtern aufgrund sehr hoher Stabilität und Leistung stark datenbezogene wissenschaftliche und technische Aufgaben. Dennoch ermöglicht die bestehende Infrastruktur vieler Institutionen die Nutzung von Linux nicht und hier können virtuelle Maschinen helfen: Sie ermöglichen es, über ein Virtualisierungs-Framework ein weiteres (guest) Betriebssystem auf dem Host-Betriebssystem zu betreiben.

Die in diesem Abschnitt vorgestellte Software ist nicht nur für Linux gemacht und kann meist auch auf vielen anderen Betriebssystemen installiert werden. Genießen Sie das Lesen und Laufen durch die Tutorials auf geospatial Software, git, numerische Modellierungssoftware und andere hilfreiche Programme.
