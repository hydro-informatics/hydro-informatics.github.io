(gdal)=
## OSGeo und GDAL einschließlich ogr und osr

Die [gdal](https://gdal.org/)-Bibliothek für {ref}`raster data handling <raster>` kommt zusammen mit [ogr](https://gdal.org/faq.html?highlight=ogr) für {ref}`vector data handling <vector>` und [osr](https://gdal.org/python/osgeo.osr-module.html) für geospatiale Referenzen. GDAL und OGR werden von der [OSGeo Project](http://www.osgeo.org/), die Teil der Open Source Geospatial Foundation ist, verwaltet und entwickelt – die Entwickler von {ref}`qgis-install`.

Die Tutorials in diesem eBook bauen auf `gdal` und `ogr` (einschließlich `osr` für räumliche Referenzierung), weshalb es wichtig ist, die Installation von `GDAL` zu erhalten:

* **Linux** Benutzer können die Anweisungen für die Installation von `gdal` und [flusstools](https://flusstools.readthedocs.io) mit {ref}`pip and venv <pip-env>` beachten.
* **Windows** Benutzer installieren vorzugsweise `gdal` und [flusstools](https://flusstools.readthedocs.io) in einem {ref}`conda environment <conda-env>` durch Anaconda.


Wählen Sie Ihre Plattform für spezifische Installationsanweisungen aus:

`````{tab-set}
````{tab-item} Linux / pip

GDAL benötigt Sudo-Installation. Weitere Informationen finden Sie in der {ref}`Python installation instructions <pip-env>` dieses eBook.

````

````{tab-item} Windows / conda
Um `GDAL` für Python zu installieren, geben Sie unter {ref}`Anaconda Prompt <install-pckg>` ein:

```python
conda install -c conda-forge gdal
```
````
`````

````{admonition} Import GDAL, ogr, and osr from OSGeo
:class: important

Das Importieren von `gdal`, `ogr` und `osr` direkt (z.B. `import gdal`) erfolgt seit GDAL v3. Daher müssen `gdal`,`ogr` und `osr` von `osgeo` importiert werden:

```python
from osgeo import gdal
from osgeo import osr
from osgeo import ogr
```
````

## Geodäsie
Die Bibliothek [geojson](https://pypi.org/project/geojson/) ist die direkteste Option für die Verarbeitung von {ref}`geojson`-Daten und ist auch bereits zusammen mit [flusstools](https://flusstools.readthedocs.io) installiert.

`````{tab-set}
````{tab-item} Linux / pip
Um `geojson` zu installieren, öffnen Sie *Terminal* und Typ:

```python
pip install geojson
```
````

````{tab-item} Windows / conda
Um `geojson` für Python Anaconda zu installieren, offen {ref}`Anaconda Prompt <install-pckg>` und Typ:

```python
conda install -c conda-forge geojson
```
````
`````

(descartes)=
## Descartes Labs
Die Bibliothek [`descarteslabs`2](https://docs.descarteslabs.com/api.html) Bibliothek (entwickelt und gepflegt von [Descartes Labs](https://www.descarteslabs.com/)]) verfügt über viele offene Funktionen. Descartes Labs beherbergt außerdem die Schaufensterplattform [GeoVisual Search](https://search.descarteslabs.com/) mit saftigen Abbildungen von künstlichen Intelligenz (KI) Anwendungen in der Geowissenschaften. Beachten Sie, dass `descarteslabs` nicht zusammen mit [flusstools](https://flusstools.readthedocs.io) installiert ist.

`````{tab-set}
````{tab-item} Linux / pip
Um `descarteslabs`, open Terminal und Typ zu installieren:

```python
pip install descarteslabs
```
````

````{tab-item} Windows / conda
Um `descarteslabs` für Python zu installieren, öffnen Sie {ref}`Anaconda Prompt <install-pckg>` und Typ:

```python
conda install -c conda-forge descartes
```

Wenn die Installation ausfällt, versuchen Sie Folgendes:

```python
conda install shapely
pip install descarteslabs
```
````
`````

## Python Imaging Library (PIL) / Kissen
Die Verarbeitung von Bildern mit Python ist mit der *Python Imaging Library* (*PIL*) aktiviert. *PIL* unterstützt viele Bilddateiformate und verfügt über effiziente Grafikverarbeitungsfunktionen. Die `pillow` Bibliothek ist eine benutzerfreundliche *PIL* Gabel und bietet `Image*`-Module (z.B.`Image`, `ImageDraw`,@@@@,`ImageMath` und vieles mehr). Wenn [flusstools](https://flusstools.readthedocs.io) installiert ist, ist keine weitere Aktion erforderlich, um mit den *PIL*/*pillow*-bezogenen Inhalten dieses eBooks zu arbeiten.

Note that the `conda base` environment includes `PIL` (test with `import PIL`), which needs to be uninstalled before installing `pillow`. For installing *PIL*/*pillow*, refer to [https://pillow.readthedocs.io](https://pillow.readthedocs.io/en/stable/installation.html).

(other-geo-pckgs)=
## Sonstige Pakete

Neben den oben genannten Paketen gibt es weitere nützliche Bibliotheken für Geospatialanalysen mit Python (**`Packages in bold red font`** werden zusammen mit [flusstools](https://flusstools.readthedocs.io)) installiert:

 * [**`alphashape`*](https://pypi.org/project/alphashape/) erzeugt gebundene Polygone mit einer Reihe von Punkten.
 * [django](https://docs.djangoproject.com/en/3.0/ref/contrib/gis/) als geographischer Webrahmen und für Datenbankverbindungen.
 * [**`geopandas`*](https://geopandas.org/) ermöglicht die Anwendung von {ref}`pandas`Datenrahmenoperationen auf geospatiale Datensätze.
 * [NetworkX](https://networkx.github.io/documentation/stable/index.html) für Netzwerkanalysen, z.B. einen kostengünstigsten / kürzesten Weg zwischen zwei Punkten.
 * [owslib](http://geopython.github.io/OWSLib/), um mit *Open Geospatial Consortium* (OGC) Webservices zu verbinden.
 * [postgresql](https://www.postgresqltutorial.com/postgresql-python/) für SQL-Datenbankverbindungen.
 * [**`rasterio`*](https://rasterio.readthedocs.io/en/latest/) für die Verarbeitung von Rasterdaten als {ref}`numpy`-Arrays.
 * [**`rasterstats`*](https://pythonhosted.org/rasterstats/) erstellt zonale Statistiken von Rastern und kann mit {ref}`geojson`-Dateien interagieren.
 * [**`sckit-image`*](https://scikit-image.org/) für maschinelles Lernen auf georeferenzierte Bilder.
