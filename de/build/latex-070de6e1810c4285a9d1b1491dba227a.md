# LaTeX & Citation Management (Zotero)

Online LaTeX editors, such as Overleaf, offer convenient, real-time collaboration and cloud-based compilation, but advanced features like handling larger documents or extensive team collaboration often require a paid subscription. In contrast, working locally with a dedicated editor like TeXstudio (see {ref}`LaTeX installation <install-tex>`) allows you to edit and compile documents without depending on an internet connection while writing/compiling and without incurring subscription costs. This page is intended to provide guidance on effectively using LaTeX in a local environment.


## Plaintext und Word Counting

Um die Anzahl der Wörter in einem LaTeX-Manuskript mit TeXstudio zu schätzen, erstellen Sie zunächst eine Klartextversion Ihres Dokuments. Wählen Sie im Menü **Tools** **Convert to Abridged Plaintext** aus, wodurch eine neue Registerkarte ohne Titel geöffnet wird, die Ihren Text ohne LaTeX-Befehle enthält. Diese abgespeckte Datei eignet sich auch für die gemeinsame Nutzung mit Mitarbeitern, die Textverarbeitung (Richtext) bevorzugen. Als nächstes wählen Sie **Analyse Text...** aus dem Tools-Menü und klicken Sie auf die Schaltfläche Zählen. TeXstudio zeigt die Anzahl der Absätze (dh Wörter) in Ihrem Text an und bietet sogar eine Häufigkeitsanalyse bestimmter Begriffe. Diese Funktionalität kann für die Verfeinerung des Manuskriptschreibstils nützlich sein, beispielsweise durch die Identifizierung einer übermäßigen Verwendung von Übergangswörtern wie "jedoch".

## Citation Management mit Zotero und Better BibTeX

### Zotero und das Better BibTeX Plugin einrichten

Better BibTeX ist ein Plugin für Zotero, das seine Referenzverwaltungsfunktionen für LaTeX-Benutzer erweitert. Es bietet Tools zum Erstellen, Verwalten und Anpassen von BibTeX- und BibLaTeX-Einträgen und ist damit ein wertvolles Zitierwerkzeug in LaTeX-Umgebungen. Better BibTeX bietet mehrere Funktionalitäten, die es zu einer bevorzugten Wahl machen:

- Citation Key Management ermöglicht die Generierung von benutzerdefinierten Citation Keys und bietet mehr Kontrolle über die Schlüsselformatierung.
- Automatischer Export und kontinuierlich aktualisierte BibTeX- und BibLaTeX-Exporte stellen sicher, dass die Bibliographie immer mit der Zotero-Bibliothek synchronisiert ist.
- Die Handhabung von Sonderzeichen verhindert BibTeX / BibLaTeX Fehler.
- Cite-as-you-write-Unterstützung für TeX (z. B. TeXstudio) und sogar Markdown-Editoren.


Um Better BibTeX für Zotero zu installieren, führen Sie die folgenden Schritte aus:

1. Stellen Sie sicher, dass Sie die neueste Version von Zotero auf Ihrem System installiert haben. Sie können es von der [Zotero-Website](https://www.zotero.org)] herunterladen.

2. Laden Sie Better BibTeX herunter:
   - Gehen Sie zum offiziellen [Better BibTeX GitHub repository](https://github.com/retorquere/zotero-better-bibtex)].
   - Download the latest release of the plugin -- make sure to choose the `.xpi` file of the lates release.

3. Installieren Sie das Plugin in Zotero:
   - Offener Zotero
   - Navigieren Sie in Zotero zu *Tools* im oberen Menü und wählen Sie *Add-ons*
   - Klicken Sie im Add-ons-Manager auf das Zahnradsymbol in der oberen rechten Ecke und wählen Sie * Add-on aus Datei installieren *
   - Locate the downloaded `.xpi` file and click *Open* - Zotero will install the plugin.
   - Starten Sie Zotero neu, um das Plugin zu aktivieren.

4. Konfigurieren Sie Better BibTeX:
   - Nach der Installation finden Sie bessere BibTeX-Einstellungen im Menü Zotero Preferences (Windows) oder Settings (Linux) unter der Registerkarte *Better BibTeX*.
   - Richten Sie Ihr Citation Key Format und Exportpräferenzen entsprechend Ihrem Workflow ein; unsere Empfehlung:
     ```
     auth.lower + year + shorttitle(1,1).lower
     ```

5. Ausfuhr und Verwendung:
   - Um eine Bibliographie zu exportieren, wählen Sie die gewünschten Referenzen in Zotero aus, klicken Sie mit der rechten Maustaste und wählen Sie *Export Items*
   - Wählen Sie *Better BibTeX* als Exportformat; Beachten Sie, dass *Better BibLaTeX* möglicherweise nicht die gewünschte Funktionalität erzeugt und unauffindbare Fehlermeldungen beim Kompilieren einer `.tex`-Datei verursacht.
   - Optional aktivieren Sie das Feld *aktualisieren* im nächsten Fenster

For the domains of water resources reasearch and hydraulic engineering, you may want to work with our hydro-informatics.com library: [https://www.zotero.org/groups/4917569/hydro-informatics/library](https://www.zotero.org/groups/4917569/hydro-informatics/library).

### Auto-Merge mehrere Duplikate

Das Zusammenführen von Duplikaten in Zotero kann durch einen Mausklick erfolgen, jedoch nur durch einen Mausklick und Einzelteil für Einzelteil. Dies kann viel Zeit in Anspruch nehmen, wenn große Bibliotheken zusammengeführt werden. Hier ist ein Workaround zum automatischen Zusammenführen mehrerer Duplikate in Zotero.

```{admonition} Make sure all duplicates have the same Item Type
:class: important

Um den folgenden Auto-Merge-Code reibungslos funktionieren zu lassen, gehen Sie durch Ihre doppelten Elemente und suchen Sie nach markierten Duplikaten, die unterschiedliche Artikeltypen haben. Als nächstes harmonisieren Sie die Elementtypen von doppelten Paaren (dh ändern Sie den Elementtyp eines der betroffenen Einträge). Das ist etwas mühsam, dauert aber nicht zu lange und viel schneller, als jedes Duplikat zusätzlich per Mausklick zusammenzuführen.
```

* Öffnen Sie die Zotero-Anwendung auf Ihrem Computer (nicht im Browser)
* Gehen Sie zum ** Duplicate Items** Eintrag Ihrer Bibliothek
* Alle markieren (drücken Sie `CTRL` und `A` Tasten)
* Gehen Sie zu **Tools** (oberes Menü) > **Developer** > **Run JavaScript**, kopieren Sie den folgenden Codeblock in das **Code**-Feld und klicken Sie auf **Run**


```
var DupPane = Zotero.getZoteroPanes();

for(var i = 0; i < 999; i++) {
  try {
    await new Promise(r => setTimeout(r, 50));
    DupPane[0].mergeSelectedItems();
    Zotero_Duplicates_Pane.merge();
  } catch (e) {
    console.log(e);
  }
}
```

Der Codeblock macht maximal 999 Iterationen, die durch Erhöhen der Iterationszahl in der For-Schleife des JavaScript-Codes erhöht werden können.


Diese Antwort ist inspiriert von Diskussionen im [Zotero Forum](https://forums.zotero.org/discussion/40457/merge-all-duplicates)].

## Bibliographie

When working with LaTeX, bibliography management typically involves using a .bib file that contains all your references, which you cite within the `.tex` document using `\cite{...}` (or similar) commands. To transform these citations and references into a properly formatted bibliography, you iteratively run a tool like BibTeX after compiling your LaTeX document. **Note that TexStudio does these iterations automatically during compiling**, so these descriptions only explain why you may see the compiling process restart several times even though you only pressed the "Compile" button once.

BibTeX liest die `.aux`-Datei einer vorherigen Zusammenstellung des `.tex`-Dokuments, sucht die relevanten Einträge in der `.bib`-Datei und erstellt dann eine `.bbl`-Datei, die nur die zitierten Referenzen enthält, die jetzt nach den Stilregeln formatiert sind, die durch eine Bibliographie-Stildatei definiert sind (z. B. eine `.bst`-Datei bei Verwendung von BibTeX). Diese Stildateien steuern das Aussehen und die Anordnung von Zitaten und Referenzen, einschließlich der Anzeige von Autoren, Titeln und Zeitschriftennamen. Sobald die `.bbl`-Datei generiert wurde, integriert LaTeX sie in das endgültige PDF-Dokument während des nächsten Kompilierungslaufs. Die `.bbl`-Datei ist somit eine vollständig formatierte Teilmenge der `.bib`-Datenbank, die sicherstellt, dass das PDF-Dokument nur die tatsächlich zitierten Referenzen anzeigt, die nach den gewählten Formatierungsrichtlinien angeordnet und gestaltet sind.

To manage your reference database and generate a `.bib` file, we recommend using tools like [Zotero](https://www.zotero.org/) (with additional tips in the {ref}`Zotero Tips <debug-zotero>` section). Our [LaTeX thesis template](https://github.com/Ecohydraulics/latex-thesis-template) provides more guidance on working with Zotero and managing the `.bib` file.
