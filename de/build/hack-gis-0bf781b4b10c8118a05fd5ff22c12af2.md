# GIS, Koordinatenreferenzsystem und Projekte

## EPSG / Koordinatenreferenzsystem / Projektion finden

Sie haben Koordinaten eines Punktes, aber Sie wissen nicht, welches geospatiale Referenzsystem es hat?

Werfen Sie einen Blick auf [projfinder.com](http://projfinder.com/):

* Geben Sie Ihre Koordinaten oben auf der Seite ein
* Zoom auf der Karte zum ungefähren Ort, wo Ihr Punkt sollte sich befinden
* Klicken Sie auf ** Meine Projektion finden**

Dank der Autoren von projfinder.com!
