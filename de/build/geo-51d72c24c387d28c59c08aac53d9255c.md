# Software für Geografik

Geospatiale Analysen (oder Analytik) verwenden, manipulieren und veranschaulichen Daten von geographischen Informationssystemen (GIS). GIS-Daten enthalten geografisch referenzierte und räumlich explizite Informationen von z.B. Schauplätzen, Geländeerhebung oder Landnutzung. Effiziente Verarbeitung von Geospatialdaten beinhaltet Programmiermethoden, bei denen *Python* ein effizientes Werkzeug ist. Diese Seite präsentiert Desktop-Software für manuelle Geospatialanalysen und die Darstellung von Geospatialdaten. Für die geospatiale Programmierung wenden Sie sich bitte an das Kapitel {ref}`sec-geo-python`.

(qgis-install)=
## QGIS
Für die Visualisierung von Geodaten (`.shp` und `.tif`Dateien) ist die GIS-Software erforderlich und die auf diesen Seiten beschriebenen Analysen beziehen sich auf die Nutzung von [QGIS](https://www.qgis.org). Dieses eBook verwendet QGIS innerhalb der Abschnitte unter {ref}`geospatial programming with Python <sec-geo-python>` und numerische Modellierung mit der Software der ETH Zürich [BASEMENT](../numerics/basement/basement).

### QGIS unter Windows installieren
Downloaden und installieren Sie die neueste Version von [QGIS](https://qgis.org/download/) für Windows. Obwohl die Entwickler die Installation von QGIS durch *OSGeo4W* empfehlen, wird dieser Weg für die Installation nicht für die Arbeit mit dem *hydro-informatics* eBook empfohlen (viele Plugin-Fehler und veraltete Bibliotheksabhängigkeiten). Deshalb, **vorzugsweise herunterladen und verwenden Sie den neuesten QGIS Standalone Installer**.

### QGIS auf Linux installieren (via Flatpak)

Die QGIS-Entwickler liefern detaillierte Installationsanweisungen für mehrere *Linux*-Vertriebe, aber die Anweisungen erfüllen nicht alle Anforderungen an die Verwendung von QGIS in diesem eBook beschrieben. Eine der funktionalsten Möglichkeiten zur Installation von QGIS auf *Linux* ist die Verwendung [Flatpak](https://flathub.org/apps/details/org.qgis.qgis), die einige Systemvorbereitungen erfordert. Auf *Debian*-basierten *Linux*-Plattformen (z.B. alle Arten von *Ubuntu* wie *Lubuntu* oder *Mint*) öffnen *Terminal* und tippen (die zweite Zeile wird nur benötigt, wenn Sie *GNOME* verwenden):

```
sudo apt install flatpak
sudo apt install gnome-software-plugin-flatpak
flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
```

Starten Sie das System neu und öffnen Sie die *Software Manager* App. Es wird das Flathub Repo aktualisieren und hinzufügen. Nachdem das Update erfolgreich war, suchen Sie nach QGIS und klicken Sie auf *Installieren* (Terrasse - die Installation kann eine Weile dauern).

The *QGIS Flatpak* installation will most likely not include the important *scipy* module. To fix this issue, open  *Terminal* (standard Linux application) and type:
<br>`flatpak run --command=pip3 org.qgis.qgis install scipy --user`

Diese Lösung wurde auf *Linux Ubuntu* und *Linux Mint* getestet. Es funktioniert möglicherweise auch mit *Red Hat*, *openSUSE*, *macOS*, *Arch*, *Fedora*, *Android*, *Debian*, *Kubuntu* und vieles mehr (lesen Sie Installationsanleitungen auf der [Website des Anbieters](https://flatpak.org/setup/)). Lesen Sie mehr über die *QGIS Flatpak*-Installation auf der [QGIS Website](https://qgis.org/download/).

### QGIS auf macOS installieren

```{admonition} macOS and BASEMENT
:class: attention
Wenn Sie BASEMENT für numerische Modellierung verwenden möchten: BASEMENT wird nicht auf macOS laufen.
```

Downloaden und installieren Sie die neueste Version von [QGIS](https://qgis.org/download/) für macOS. Die Integrität der Verwendung von macOS für die Anwendungen in diesem ebook wurde noch nicht getestet. Mögliche Fehlerbehebung mit *Python* wird z.B. von [kyngchaos.com](https://www.kyngchaos.com/software/qgis/).

### Lernen Sie QGIS
Die Zusammenarbeit mit Geospatial Data Editoren beinhaltet komplexe Aufgaben, die Hintergrundwissen erfordern, bevor ein intuitives Verständnis möglich ist. Die QGIS-Entwickler stellen auf ihrer Website](https://docs.qgis.org/latest/en/docs/training_manual/index.html) ([auch in anderen Sprachen wie Französisch, Deutsch und Portugiesisch](https://docs.qgis.org/latest/)) eine Verbindung zur Verfügung.
Dieses eBook verwendet gelegentlich QGIS zur Erstellung von georeferenzierten Daten (z.B. die Kapitel über {ref}`sec-geo-python` und {ref}`numerical modeling <qgis-prepro-bm>`). Zu diesem Zweck kommt dieses eBook zusammen mit einem Tutorial zu geospatialen Analysen mit QGIS (lesen und tun Sie die {ref}`qgis-tutorial`).

(qgis-conda-install)=
### QGIS conda Environment installieren

In {ref}`Anaconda Prompt <anaconda>` können Sie eine neue Umgebung schaffen, um QGIS-Funktionen (z.B. Werkzeuge und Skripte) einschließlich seines Rasterrechners gezielt zu nutzen. Die Umgebung wird von *Open Data Cube* ([mehr](https://datacube-qgis.readthedocs.io/en/latest/installation.html)) angeboten und kann wie folgt installiert werden:

```
conda create  -c conda-forge -n qgiscube python=3.11 qgis datacube
conda activate qgiscube
```

## GESELLSCHAFT

```{admonition} Windows only
:class: attention
ArcGIS ist für Windows konzipiert und wird nicht auf macOS oder Linux laufen. Darüber hinaus muss eine Lizenz gekauft werden.
```

Die proprietäre Software *ArcGIS Pro* stellt ein leistungsstarkes Werkzeug für jede Art von geospatialer Analyse einschließlich Web-Anwendungen dar. *ArcGIS Pro* wird von [esri](https://www.esri.com/) und kommt mit einer eigenen {ref}`conda-env`. Mit dem Fokus dieses eBooks auf frei verfügbare Software wird die Nutzung von *ArcGIS Pro* und dessen *Python*-Umgebung einschließlich des `arcpy`Pakets auf dieser Website gerade erwähnt.

* [Mapline](https://mapline.com/)
* [Mapbox](https://www.mapbox.com/)
* [uDig](http://udig.refractions.net/)
