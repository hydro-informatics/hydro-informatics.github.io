# Python Übungen

This section provides exercises that align with the *Python* basics presented in this eBook. Code templates including *README* markdown files with instructions for the exercises are hosted in external repositories (visit [https://github.com/Ecohydraulics](https://github.com/Ecohydraulics) and look for the *Exercise-* repositories).

Die Inhalte des Trainings umfassen die Gestaltung von Reservoirs, die Berechnung von Hochwasserrückkehrzeiten, einfache hydraulische Berechnungen und Schätzungen des Sedimenttransports. Jede Übung beginnt mit einer Erklärung des physischen Hintergrunds der Anwendungen.

Die folgende Tabelle fasst die Praxisanwendung und die Codierungsaspekte der Übungen auf den folgenden Seiten zusammen:

| Bewerbung | Schulungsziel |
|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
| 1d Hydraulik (Manning-Strickler Solver) | Loops, Iterationen und Funktionen |
| Reservoir-Design (Sequent Peak) | Datenverarbeitung mit {ref}`numpy`, Kommunikation mit *csv* Dateien |
| Berechnung der Hochwasserrückgabeperioden | Daten- und CSV-Dateiverarbeitung mit {ref}`pandas` |
| 1d Sedimenttransport | {ref}`ooc`, {ref}`sec-xlsx` und Plotting |
| Erstellen einer grafischen Benutzeroberfläche (GUI) | vertraut machen mit {ref}`chpt-gui` |
