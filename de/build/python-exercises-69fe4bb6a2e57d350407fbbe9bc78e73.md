# Python Übungen

This section provides exercises that align with the *Python* basics presented in this eBook. Code templates including *README* markdown files with instructions for the exercises are hosted in external repositories (visit [https://github.com/Ecohydraulics](https://github.com/Ecohydraulics) and look for the *Exercise-* repositories).

Die Lehrinhalte umfassen die Konstruktion von Reservoiren, die Berechnung von Flutrücklaufzeiten, einfache hydraulische Berechnungen und Sedimenttransportschätzungen. Jede Übung beginnt mit einer Erklärung des physischen Hintergrunds der Anwendungen.

Die folgende Tabelle fasst die Praxisanwendung und die in den Übungen auf den folgenden Seiten enthaltenen Kodierungsaspekte zusammen:

| Anwendung | Trainingsziel |
--------------------------------------------------------------------------------------------
| 1d Hydraulische (Manning-Strickler-Lösungsmittel) | Schlaufen, Iterationen und Funktionen |
| Reservoir Design (Sequent Peak) | Datenverarbeitung mit {ref}`numpy`, Kommunikation mit *csv* Dateien |
| Daten- und csv-Dateibearbeitung mit {ref}`pandas` |
| 1d Sedimenttransport | {ref}`ooc`, {ref}`sec-xlsx` und Grundstücke |
| Erstellen Sie eine grafische Benutzeroberfläche (GUI) | vertraut mit {ref}`chpt-gui` |
