Software für Geografik

Geospatiale Analysen (oder Analytik) verwenden, manipulieren und veranschaulichen Daten von geographischen Informationssystemen (GIS). GIS-Daten enthalten geografisch referenzierte und räumlich explizite Informationen von z.B. Schauplätzen, Geländeerhebung oder Landnutzung. Effiziente Verarbeitung von Geospatialdaten beinhaltet Programmiermethoden, bei denen Python ein effizientes Werkzeug ist. Diese Seite präsentiert Desktop-Software für manuelle Geospatialanalysen und die Darstellung von Geospatialdaten. Für die geospatiale Programmierung wenden Sie sich bitte an das Kapitel Geodäsie Python.

QGIS¶

Für die Visualisierung von Geodaten (.shp und .tifDateien) ist die GIS-Software erforderlich und die auf diesen Seiten beschriebenen Analysen beziehen sich auf die Nutzung von QGIS. Dieses eBook verwendet QGIS innerhalb der Abschnitte unter geospatial programming with Python und numerische Modellierung mit der Software der ETH Zürich BASEMENT.

QGIS unter Windows installieren¶

Downloaden und installieren Sie die neueste Version von QGIS für Windows. Obwohl die Entwickler die Installation von QGIS durch OSGeo4W empfehlen, wird dieser Weg für die Installation nicht für die Arbeit mit dem hydro-informatics eBook empfohlen (viele Plugin-Fehler und veraltete Bibliotheksabhängigkeiten). Deshalb, vorzugsweise herunterladen und verwenden Sie den neuesten QGIS Standalone Installer.

QGIS auf Linux installieren (via Flatpak)¶

Die QGIS-Entwickler liefern detaillierte Installationsanweisungen für mehrere Linux-Vertriebe, aber die Anweisungen erfüllen nicht alle Anforderungen an die Verwendung von QGIS in diesem eBook beschrieben. Eine der funktionalsten Möglichkeiten zur Installation von QGIS auf Linux ist die Verwendung Flatpak, die einige Systemvorbereitungen erfordert. Auf Debian-basierten Linux-Plattformen (z.B. alle Arten von Ubuntu wie Lubuntu oder Mint) öffnen Terminal und tippen (die zweite Zeile wird nur benötigt, wenn Sie GNOME verwenden):

sudo apt install flatpak
sudo apt install gnome-software-plugin-flatpak
flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo

Starten Sie das System neu und öffnen Sie die Software Manager App. Es wird das Flathub Repo aktualisieren und hinzufügen. Nachdem das Update erfolgreich war, suchen Sie nach QGIS und klicken Sie auf Installieren (Terrasse - die Installation kann eine Weile dauern).

The QGIS Flatpak installation will most likely not include the important scipy module. To fix this issue, open Terminal (standard Linux application) and type:
flatpak run --command=pip3 org.qgis.qgis install scipy --user

Diese Lösung wurde auf Linux Ubuntu und Linux Mint getestet. Es funktioniert möglicherweise auch mit Red Hat, openSUSE, macOS, Arch, Fedora, Android, Debian, Kubuntu und vieles mehr (lesen Sie Installationsanleitungen auf der Website des Anbieters). Lesen Sie mehr über die QGIS Flatpak-Installation auf der QGIS Website.

QGIS auf macOS installieren¶

macOS and BASEMENT

Wenn Sie BASEMENT für numerische Modellierung verwenden möchten: BASEMENT wird nicht auf macOS laufen.

Downloaden und installieren Sie die neueste Version von QGIS für macOS. Die Integrität der Verwendung von macOS für die Anwendungen in diesem ebook wurde noch nicht getestet. Mögliche Fehlerbehebung mit Python wird z.B. von kyngchaos.com.

Lernen Sie QGIS¶

Die Zusammenarbeit mit Geospatial Data Editoren beinhaltet komplexe Aufgaben, die Hintergrundwissen erfordern, bevor ein intuitives Verständnis möglich ist. Die QGIS-Entwickler stellen auf ihrer Website](https://docs.qgis.org/latest/en/docs/training_manual/index.html) (auch in anderen Sprachen wie Französisch, Deutsch und Portugiesisch) eine Verbindung zur Verfügung. Dieses eBook verwendet gelegentlich QGIS zur Erstellung von georeferenzierten Daten (z.B. die Kapitel über Geodäsie Python und numerical modeling). Zu diesem Zweck kommt dieses eBook zusammen mit einem Tutorial zu geospatialen Analysen mit QGIS (lesen und tun Sie die QGIS Tutorial).

QGIS conda Environment installieren¶

In Anaconda Prompt können Sie eine neue Umgebung schaffen, um QGIS-Funktionen (z.B. Werkzeuge und Skripte) einschließlich seines Rasterrechners gezielt zu nutzen. Die Umgebung wird von Open Data Cube (mehr) angeboten und kann wie folgt installiert werden:

conda create  -c conda-forge -n qgiscube python=3.11 qgis datacube
conda activate qgiscube

GESELLSCHAFT¶

Windows only

ArcGIS ist für Windows konzipiert und wird nicht auf macOS oder Linux laufen. Darüber hinaus muss eine Lizenz gekauft werden.

Die proprietäre Software ArcGIS Pro stellt ein leistungsstarkes Werkzeug für jede Art von geospatialer Analyse einschließlich Web-Anwendungen dar. ArcGIS Pro wird von esri und kommt mit einer eigenen conda / mamba - empfohlen unter Windows 11 & plattformübergreifende Datenwissenschaft. Mit dem Fokus dieses eBooks auf frei verfügbare Software wird die Nutzung von ArcGIS Pro und dessen Python-Umgebung einschließlich des arcpyPakets auf dieser Website gerade erwähnt.

Sonstige¶

Es gibt viele andere Werkzeuge für geospatiale Analysen, die alle verdienen viel mehr als nur hier erwähnt werden. Aus praktischen Gründen konzentriert sich diese Website auf die Nutzung von QGIS. Deshalb gibt es hier nur eine absolut nicht vollständige Liste anderer GIS-Tools:

  • SAGA (System für automatisierte geowissenschaftliche Analysen)

  • Mapline

  • Mapbox

  • uDig

Geoanalysen¶

Geospatialanalysen beinhalten effiziente Code-Praktiken (z.B. mit Python) und deshalb sind detaillierte Beschreibungen der Geospatialdatenverarbeitung in das Geodäsie Python Kapitel dieses eBooks eingebettet.
