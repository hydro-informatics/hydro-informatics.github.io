Charriage sur l’Arbogne : Getreide, rugosité et chartme de Shields

Pour travailler de manière interactive : , ou télécharger le paquet de l’exercice (fichier zip) et l’ouvrir en local avec JupyterLab.

Le paquet contient trois fichiers qui doivent rester *dans le même dossier :

| fichier | contenu | |------| | bedload-exercise.ipynb | ce Notebook, le seul fichier à modifier | | charriage.py | le code technology :: formule de Meyer-Peter & Müller (MPM), contrôle et numbers | | hecras-arbogne.csv | l’hydraulique de 16 profils HEC-RAS 1D de l’Arbogne à Dompierre (FR) pour Q = 25 m3^33/s |

Tâche : votre expert est demandée pour analyser le risque d’alluvionnement dans le tronçon revitalisé de l’Arbogne. Un collègue vous a fourni l’hydraulique (1D) de 16 profils sur 890 m. Où le gravier s’arrête-t-il, et que se passe-t-il quand la végétation freine l’écoulement ?

Struktur de l’exercice¶

partiequi travaille
Ipréparation : charger le script et les donnéesdonné : exécuter les cellules
IIdonnées : granulométrie, rugosités kstk_{st}kst​, seuil τ∗,cr\tau_{*,cr}τ∗,cr​vous : compléter deux listes
IIIéquations : rapport de rugosité k′k'k′ et rugosité critique kst,crk_{st,cr}kst,cr​vous : compléter deux lignes de code

Il n’est pas nécessaire de savoir Programmierer. Une Cellule s’exécute avec Maj + Entrée (Shift + Enter). Les endroits à compléter sont marqués par le commentaire # >>> À COMPLÉTER: remplacez chaque texte">>> COMPLETER" (guillemets compris) par votre valeur ou votre équation. Dans le code, les nombres décimaux s’écrivent avec un point (0.047 et non 0,047).

La cellule suivante charge le script charriage.py sous le nom abrégé ch. Sur Google Colab, elle télécharge d’abord le script et les données. Cette cellule ne contient pas de matière du cours.

Bilder von Shields¶

Le chartme vergleichen les deux cas de rugosité, sans végétation (écoulement dans le lit) et avec végétation (crue débordante dans la schlichte inondable), pour les deux classs de Korn, gravier et sable. Chaque point est un profil. L’axe vertikal est la contrainte efficace sur les Korns k′ τ∗k'\,\tau_*k′τ∗​, Celle que MPM vergleichen àτ∗,cr\tau_{*,cr}τ∗,cr​. Sous la courbe de Shields critique, il n’y a pas de charriage.

  • couleur: cas de rugosité (bleu sans végétation, rouge avec végétation) ;

  • symbole: Körnerklasse (Brond : Gravur; Dreieck : sable)

  • taille : Φ\PhiΦ, une décade par classe (le plus grandΦ\PhiΦ donne le plus grand marqueur).

ch.diagramme_shields(resultats)

Anmerkung: avecdmd_mdm​ = 0,23 mm, le sable est hors du domaine de validité de MPM (Umwelt 0,4 à 30 mm). Son résultat n’est qu’un ordre de grandeur.

Questions : la végétation déplace-t-elle le gravier et le sable de la même manière ? Pour quelle classe de Korn la végétation fait-elle passer les points sous la courbe ?
