Geschiebe an der Arbogne: Korn, Rauheit und Shields-Diagramm

Dieses Notebook im Webbrowser ausführen:

Der Link öffnet bedload-exercise.py als interaktives marimo-Notebook, das vollständig im Webbrowser läuft, ohne dass etwas installiert werden muss. Wie das Jupyter-Notebook ist das marimo-Notebook die französische Originalfassung dieser Seite.

  1. Warten Sie einen Moment, bis Python im Browser geladen ist (das dauert nur beim ersten Start länger).

  2. Klicken Sie auf den gelben Ausführen-Button (▶︎, unten rechts), um alle Zellen auszuführen.

  3. Bearbeiten Sie beliebige Code-Zellen und führen Sie sie erneut aus: marimo aktualisiert automatisch alle davon abhängigen Zellen.

  4. Ihre Änderungen bleiben nur im Browser-Tab erhalten. Um sie zu behalten, speichern Sie das Notebook über das Menü (☰, oben rechts) > Export… > Python.

Dieses marimo-Notebook lokal ausführen

Um bedload-exercise.py auf dem eigenen Rechner auszuführen, holen Sie es aus dem Repository marimo-python-course:

  1. Klonen Sie das Repository: git clone https://github.com/sschwindt/marimo-python-course.git

  2. Erstellen und aktivieren Sie die Kursumgebung: conda env create -f environment.yml und conda activate hy-marimo

  3. Starten Sie das Notebook im Repository-Ordner mit marimo edit bedload-exercise.py

Dieses Notebook mit Jupyter ausführen

Diese Seite gibt es auch als Jupyter-Notebook bedload-exercise.ipynb im Repository jupyter-python-course. Starten Sie es auf oder , oder laden Sie das Notebook herunter und installieren Sie Python sowie JupyterLab lokal, um bedload-exercise.ipynb auf dem eigenen Rechner auszuführen. Das Notebook auf Binder, Colab und GitHub ist die französische Originalfassung dieser Seite.

Aufgabe

Ihre Expertise ist gefragt, um das Risiko von Auflandungen im revitalisierten Abschnitt der Arbogne zu analysieren. Ein Kollege hat Ihnen die (1D-)Hydraulik von 16 Querprofilen auf 890 m geliefert. Wo bleibt der Kies liegen, und was passiert, wenn Vegetation die Strömung bremst?

Aufbau der Übung¶

Die zu ergänzenden Stellen sind mit dem Kommentar # >>> À COMPLÉTER (zu ergänzen) markiert: Ersetzen Sie jeden Text ">>> COMPLETER" (inklusive Anführungszeichen) durch Ihren Wert oder Ihre Gleichung. Im Code werden Dezimalzahlen mit einem Punkt geschrieben (0.047 und nicht 0,047).

Der Code ist französisch, wie die marimo- und Jupyter-Notebooks: Variablen- und Funktionsnamen, Kommentare und die Meldungen von charriage.py. Shields-Diagramm¶

Das Diagramm vergleicht die beiden Rauheitsfälle ohne Vegetation (Abfluss im Gerinne) und mit Vegetation (Hochwasser ufert in das Vorland aus) für beide Kornklassen, Kies und Sand. Jeder Punkt ist ein Querprofil. Die vertikale Achse ist die wirksame Schubspannung auf die Körner k′ τ∗k'\,\tau_*k′τ∗​, also diejenige, die MPM mit τ∗,cr\tau_{*,cr}τ∗,cr​ vergleicht. Unterhalb der kritischen Shields-Kurve findet kein Geschiebetransport statt.

  • Farbe: Rauheitsfall (blau ohne Vegetation, rot mit Vegetation);

  • Symbol: Kornklasse (Kreis: Kies; Dreieck: Sand);

  • Größe: Φ\PhiΦ, eine Dekade pro Klasse (das größte Φ\PhiΦ ergibt die größte Markierung).

ch.diagramme_shields(resultats)
Note

Mit dmd_mdm​ = 0,23 mm liegt der Sand außerhalb des Gültigkeitsbereichs von MPM (etwa 0,4 bis 30 mm). Sein Ergebnis ist nur eine Größenordnung.

Fragen

Verschiebt die Vegetation den Kies und den Sand auf die gleiche Weise? Bei welcher Kornklasse lässt die Vegetation die Punkte unter die Kurve fallen?
